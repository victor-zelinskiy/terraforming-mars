# TR77 SEPTEM TRIBUS:REDUX — кубы на знамёнах партий

*(2026-10-25. Корпорация-замена набора Turmoil Redux — седьмая строка реестра замен, единственная корпорация среди них.
Не загружается автоматически; читать при работе с грантами эффекта партии, режимом Парламента `banner`, битом заседания
«куб на знамя».)*

## 2. Механика — КУБ = ГРАНТ

Куб на знамени — это `Parliament.grantPartyEffect(player, party, CardName.SEPTEM_TRIBUS_REDUX)`: резерв, который
Парламент держал со времён TR36 (D1, `TURMOIL_REDUX_COUNCIL_SEAT.md` §2.3). Второго состояния нет: грант идемпотентен по
`(party, source)`, а правила не различают один куб и несколько (владелец) — один куб на знамя на игрока.

- **FAQ p.19**: грант даёт ЭФФЕКТ, никогда требование (`access().satisfiesRequirement` грантов не читает) и никогда не
  включает альянс TR62 (`printedStanding`). Карта с требованием партии при одном кубе не играется; причина в руке получает
  `UnplayableReason.effectOnly: 'banner'` → строка «ваш куб на знамени даёт эффект, но не это требование».
- **Какие источники рисуются кубом** — `common/parliament/bannerCubes.ts` (`BANNER_CUBE_SOURCES`, `bannerPartiesOf`). Грант
  любого другого источника остаётся «выдан источником «X»».
- **Публичность**: гранты каждого места уже в `ParliamentModel.players[].access[].granted` — кубы соперников видит каждый.
- **Уход корпорации**: `onDiscard` отзывает все гранты источника (решение 4а). Сегодня ни одна дорога игры корпорацию со
  стола не снимает (`discardPlayedCard` — проектные карты), это честный ответ на будущее.

### 2.1 Первое действие — `parliament/PlaceBannerCube.ts`

`initialAction` откладывает шаг `PlaceBannerCube` → `SelectParty` с маркером **`bannerPrompt`**
(`{source: 'first-action', parties: [{party, available, hasCube, hasEffect, reason?}]}`), `choiceContext` — корпорация.
`previewSelectParty()` = исполнение. Знамя, где куб уже стоит, — отказ с причиной; все знамёна заняты — именованный пропуск.
`placeBannerCube` — одна операция: грант + строка журнала + событие **`banner-cube-placed`** (`impact.bannerCube`, ряд
журнала «Знамя партии · X»). Доступ анонсирует общий дифф (`announceAccessChanges`, дорога `card`, источник — токен карты).
Брифинг первого действия говорит «после подтверждения выберите партию» (прецедент Vitor).

### 2.2 Победа на резолюции — `ICard.onResolutionWon`

Новый хук заседания, по образцу `onRulingPartyChanged`: `ParliamentPhase.stepEnact` после хуков смены власти, под ключом
`enact:`, внутри `withEffect(…, 'resolution-won')`, только победителю-игроку (никогда нейтральному, никогда MarsBot).
Выигравшая партия с этого мига правит — анонс доступа молчит; в следующем поколении дорога меняется на `card` под стоящим
эффектом — не новость. Новый грант баннерного источника ИЗМЕРЯЕТСЯ в сводку заседания `bannerCubes` (`{player, party,
card}`) — клиентский бит читает запись, а не дифф. Куб, уже стоявший, ничего не пишет. Спек: `tests/parliament/ResolutionWonHook.spec.ts`.

## 3. Консоль

- **Куб на знамени виден везде**: плашка партии (`ConsolePartyPlaque` — гнездо в правом нижнем углу печати, зеркало
  бейджа альянса, `data-banner-cube="<color>"`) и Хартия (`PremiumPartyFace` — гнёзда в углу полотна вымпела,
  `data-charter-banner-cube`; хосты с моделью передают `partyPremiumVm(party, {bannerCubes})`). Материал, без ореола.
- **Удержание до касания** (`console/parliament/bannerCubeScene.ts`): `seedBannerCubeHolds` в обоих блоках применения вида
  держит только тот куб, который кто-то сыграет (собственный ответ на `bannerPrompt` или куб из записи заседания); куб
  соперника просто стоит. Сетка `BANNER_CUBE_HOLD_MAX_MS` показывает неслетевший куб (граница, не бит).
- **Режим Парламента `banner`** («ЗНАМЯ», `ConsoleParliamentBannerMode.vue` + `bannerPickModel.ts`): кольцо режима поддержки
  по шести плашкам, под курсором — ПРИЗРАК куба (пунктир + бледный куб), панель чтения (партия, что даст куб, печатный
  эффект партии, строка FAQ), A «Поставить куб» — один POST; ответ: куб летит с места игрока на скамье в гнездо
  (`flyBannerCube` — та же переноска «взял → понёс → поставил», тело — куб игрока), открытый эффект — печать партии в
  «ВАШИ ЭФФЕКТЫ» (сцена доступа, лента молчит — `accessToldOnStage` теперь и для дороги `card`), чтение, уход.
- **Стадия старта**: строка `start` → `frameSteps: {awards: 'scene', parliament: 'scene'}`; оболочка пушит кадр
  Парламента над стартом («СТАРТ ПАРТИИ › SEPTEM TRIBUS › ЗНАМЯ», фаза committed, B «Свернуть»), как награды Vitor.
  Три гочи, найденные e2e: ① `taskFor` знал `party` только по `votePrompt` / `delegatePrompt` — промпт-знамя был `unknown`
  (застрявший промпт); маркер `bannerPrompt` классифицирован; ② спад `consoleForegroundBusy` не наступает после
  подтверждения первого действия — шаг открывает свой сигнал `bannerStepDue` (восходящий фронт); ③ шаг-сцена рисует СВОЙ
  заголовок — для кадра с хостом `start` Парламент берёт крошку стека (образец `ConsoleMaScreen`) и не перезаписывает
  субъект кадра (корпорация).
- **Бит заседания «куб на знамя»** (`sittingDirector.beatBanner`, удержание `parliament-sitting:enact/banner`): после хода
  принятия — куб с места победителя на скамье в гнездо правителя. Отклонение от решения 7а: бит идёт ПОСЛЕ «делегаты домой»
  (ход принятия — один таймлайн; вставка в середину потребовала бы разрезать его), источник — место игрока, тот же закон, что
  у первого действия.
- **Фраза дороги** (решение 5а): «Эффект ваш · куб на знамени», «Доступен · ваш куб на знамени», «уже ваш: куб на знамени»;
  `EffectWhy 'banner'` в «ВАШИ ЭФФЕКТЫ».
