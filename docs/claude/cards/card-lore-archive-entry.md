## Archive entry — the card's LORE in the fullscreen viewer (`CardLoreAside`)

The fullscreen card viewer is a THREE-ZONE composition: **[ ЗАПИСЬ ИЗ АРХИВА ] · [ CARD — dead centre ] · [ ПРАВИЛА / СТАТИСТИКА ]**. The right side is technical (the structured rules panel / the blue-action dossier); the LEFT is the card's literary flavour text. It exists in the TRUE fullscreen inspect ONLY — never in a card list, the Action Focus hero, a compact zoom, the rules panel, the statistics tab, a tooltip, the journal, or the card face itself.

**One implementation at the one shared level.** `CardZoomModal` is the single fullscreen presentation of the app (desktop hosts + every console context through `consoleCardZoom`), so `CardLoreAside.vue` is mounted THERE, behind the opt-in `lore` prop. ConsoleShell passes `:lore="true"`; desktop binds nothing → byte-identical (its viewer fills BOTH gutters with the floating `CardAnnotationsLayer` callouts, which a left-hand block would collide with — the same reason `annotationsSuppressed` exists). A bonus (Automa) zoom entry is not a card and never shows one.

**Data + `reimplements` resolution live in the pure `src/client/cards/cardLore.ts`** — the sibling of `cardArt.ts`, and deliberately the same borrow idiom: the corpus `assets/text/lore_texts.json` is keyed by `metadata.cardNumber`; a card with no entry of its own falls through `metadata.reimplements` (promo/Ares reissues) with a `seen` cycle guard. English IS the i18n key (no `en/` locale); `src/locales/ru/lore_texts.json` is auto-merged into `assets/locales/ru.json` by `make:json`. `buildCardLoreModel(name, translate)` takes the translator as a PARAMETER (no Vue/DOM/i18n import) and returns the finished display string + `fallback` + the length `tier`, so the component never does a lookup in its render.

- **⚠️ Lore is PROSE — it opts out of `translateText`'s "non-word" guard** (`translateText(text, {translateNonWordText: true})`). That guard exists for card-render fragments (`x`, `3x`); without the opt-out a whole entry made of digits + a full stop («42.» — AI Central) stays permanently untranslated. `translateText` now takes an options arg, so it can no longer be passed point-free to `.map()`.
- **Typographic tiers by the LOCALIZED length** (`short` ≤65 / `regular` ≤170 / `extended`) — optical compensation only; the entry is ALWAYS shown in full: no scroll, no truncation, no ellipsis, no "read more".
- **Fallback:** a card with no entry still renders the block, with a localized notice (`No archive entry is available.` → «Архивная запись отсутствует.») in a muted style + a ONE-PER-CARD dev warning. Every card in the premium-face scope has real lore and `cardLore.spec.ts` FAILS the moment one starts falling back.

**STRICT CENTRING is the load-bearing layout rule.** The viewer's midrow used to be a centred FLEX row, which centres the card+panel GROUP and therefore pushes the card off-centre by half the flank. With any gutter filled the row now takes `.card-zoom-midrow--flank` (`card_lore.less`): a grid `minmax(0,1fr) auto auto auto minmax(0,1fr)` with EVERY child explicitly placed (so a hidden nav control — console hides the touch chevrons — cannot shift its siblings into the wrong column). The card owns the middle column; the two `1fr` gutters are equal by construction. Breathing room is a MARGIN on each flank, never a `column-gap` (a margin lives inside its own gutter and so cannot move the centre column; a gap around the two empty nav tracks would be applied twice per side). `fitCardToViewport` mirrors this: it reserves `2 × max(loreReserve, sideReserve)` — reserving one side only would let the wider gutter overrun the card.

**Presentation:** never a second panel. No border, head bar, glass, buttons, hover, focus, scroll; `pointer-events: none`; the only backdrop is a radial darkening that fades to zero inside the element box. Warm ivory / muted gold tokens (`--zlore-*`) against the rules side's cold cyan, and NEVER tinted by card type (a coloured literary text would read as a rule). Semantics: `<aside>` → `<h2>` heading → `<blockquote :lang>`.

- **⚠️ NO VERTICAL RULE — the load-bearing reset.** Spectre.css styles EVERY `blockquote` with `border-left: .1rem solid #dadee4`; at the console rem base that is a 2–4 px light-grey bar, and it made the entry read as a Markdown quote / a text caret / the edge of another panel (zeroing `margin`+`padding` is not enough — `border: 0` is). The composition is held by the heading, its trace, the two marks and NEGATIVE SPACE. Never reintroduce a left border, a glowing strip, a bracket or any other long vertical element. Guarded in the e2e (real CSS: all four computed border widths are `0px`).
- **A STAIRCASE, not a quote block:** heading at the block's left edge → the opening mark indented (`left: .6rem`) → the text indented further (`--zlore-indent`, 2.5rem). The text therefore never starts under the mark and is never "inside" a quotation.
- **The marks are a LOCAL inline SVG pair** (`MARK_*` in `CardLoreAside.vue`): one comma = a bowl `<circle>` + a tail `<path>`, drawn twice; the closing mark is the SAME glyph rotated 180° in CSS — the real typographic relationship between “ and ”. Drawn, not typed: identical on Windows / SteamOS AND identical in Literata and Newsreader (a font glyph would differ between the two faces), and its weight tunes independently of the text. `aria-hidden` + `focusable="false"` + `pointer-events: none`; **nothing is ever added to the lore string** (entries already carry «», ‘’, dashes and one full JFK quotation). No emoji, no external asset, no filter, no mask.
- **The closing mark tracks the real text height.** The blockquote is `width: fit-content` (capped by the tier's `max-width`), so it HUGS a one-line aphorism and saturates for a wrapping one; the mark is anchored to that box's bottom-right, giving a constant gap under the last line for every entry instead of a fixed far-away coordinate. It is smaller and fainter than the opening mark — a flourish, not a mirrored icon.
- **Typography:** `font-synthesis: none` (a real italic 500 from the variable file — never a faux slant or faux bold), `font-kerning: normal`, `font-optical-sizing: auto`, `font-variant-numeric: lining-nums`, a hair of tracking for TV distance. Verified against the awkward strings: E=mc², N₂/CO₂, «внутренние кавычки», an em dash, a JFK quotation, Latin corporate names inside Russian prose.

**Reveal choreography** rides the viewer's existing settle nonce (bumped when the card has LANDED — open settled / LB-RB slide finished). ONE quiet entrance, not four effects: heading+trace lead, the text follows at +55 ms, the opening mark rides almost with it (+70 ms, softer), the closing mark lands at +110 ms — offsets in tens of ms, ~250 ms each, `translateX(7px)` from the card outward plus a transient 1.8 px blur on the text only. A browse step hides FIRST and swaps the text only at the next settle, so two entries are never legible at once and no height change snaps into view. `closing` hides it instantly. `prefers-reduced-motion` → a short opacity fade only, no travel/blur (the closing mark keeps its 180° rotation — that is its glyph, not motion); the `con-perf-lite` profile strips the decorative blur and nothing functional is lost.

**Visual harness:** `?lorePlayground` (`CardLorePlayground.vue`, dev-only async chunk, mirrors the other playgrounds) renders the REAL component over the REAL corpus in every text shape that the composition has to survive — aphorism / slogan / technical / ironic / inner quotes / formulae / a full quotation / the two longest corporate paragraphs / fallback — with an RU⇄EN switch, because a translation routinely wraps to a different number of lines. Use it before touching the typography.

**Fonts** (`common.less`): self-hosted OFL italic weight-variable subsets — **Literata** for Cyrillic locales (`ru`/`ua`/`bg`, latin subset included so punctuation stays in voice) and **Newsreader** for everything else. Chosen by the ACTIVE LOCALE (`loreScriptForLocale`), never by sniffing the string. `unicode-range` + `font-display: swap` mean they are fetched only when an archive entry first paints. A new `.woff2` needs THREE plumbing entries: `ContentType`, `ServeAsset.toFile`'s allowlist, and `electron/protocol.ts` (`ASSET_EXT` + MIME).

Tests: `tests/client/components/card/cardLore.spec.ts` (resolution / reimplements / localization / tiers / quoted content / fallback / full-scope coverage), `CardLoreAside.spec.ts` (render, semantics, SVG marks, no-border, choreography), `CardZoomModalLore.spec.ts` (fullscreen-only gating, flank composition, browsing), `tests/routes/ServeAsset.spec.ts` (the font files), `tests/e2e/console-card-lore.spec.ts` (the real console fullscreen at fhd + tv4k: strict centring ≤2 px, the killed Spectre border, real italic 500, the marks framing the text, LB/RB, reduced motion — `serial`, since the two profiles drive one shared dev server).
