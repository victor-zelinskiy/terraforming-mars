# `docs/claude/archive/`

Reserved for material judged **obsolete** — superseded designs, abandoned plans, changelogs of work that no longer constrains new code.

**Status at the 2026-07-27 split: empty on purpose.** Every section of the old root `CLAUDE.md` was audited and each turned out to still describe a shipped, live subsystem, so all of it moved to `docs/claude/**` as active reference rather than here. Nothing was deleted; the byte-for-byte original is `CLAUDE.md.backup.md` at the repo root.

The closest thing to "completed work" is `docs/claude/desktop-ui/` — the desktop surface is FROZEN, so those write-ups are no longer instructions to extend. They stay out of the archive because the console port reads them as the **design spec** for what to rebuild.

When you do retire something, move the file here and drop its row from `docs/claude/README.md`.
