# Стандарт русского перевода карт — ВЫСОКАЯ ПЛАНКА

**Читать ДО того, как писать любой RU-текст карты** — новой карты (Turmoil Redux, Prelude 2, промо, MarsBot), адаптации
апстрим-карты, её подсказок, промтов, чипов, журнала и лора. Решение владельца 2026-11-01: «в новых картах часто хромает
перевод терминов — странные, не используемые и нелитературные переводы (ресурс «рычаг»); стремимся к более лаконичным и
понятным текстам». Первая итерация аудита по этому стандарту — коммит `797f4c284a`.

## 1. Планка

Текст карты читается как **печатная русская локализация** («Покорение Марса», Crowd Games), а не как подстрочник:

1. **Адаптивно, не калькой.** Переводим СМЫСЛ игрового термина словом, которое русский игрок поймёт без английского
   оригинала. `leverage` — не «рычаг» (в русском это не ресурс), а **«сделка»** (спрайт — рукопожатие, ресурс копится за
   метки планет и покупает делегатов — это и есть сделки).
2. **Общепринято.** Если в проекте или в печатном издании слово уже есть — берём его, даже если «своё» кажется точнее.
   Один термин = одно слово во всём корпусе.
3. **Литературно.** Грамотные согласования, падежи, порядок слов; никаких «1 данные», «с 38 M€ и +1 к производству»,
   «Требует, чтобы … правила».
4. **Лаконично и понятно.** Короче английского, если смысл не теряется: «разыграв метку Науки» вместо «каждый раз после
   того, как вы разыграли карту с меткой науки». Канцелярит и вода — вон.
5. **Точно.** Числа, условия, «ЛЮБУЮ / свою», «включая эту» — ровно как в `description` карты. Красивый, но неверный
   текст хуже кальки.

## 2. Источники истины — по порядку

1. **Корпус проекта**: `grep` по `src/locales/ru/*.json` — устоявшееся слово побеждает.
2. **Печатное издание** (Crowd Games) — названия меток, вех, наград, стандартных проектов, ресурсов. Если проект
   расходится с печатью — НЕ выбирать молча, а вынести расхождение владельцу.
3. **`docs/claude/parliament-glossary.md`** — всё, что касается Парламента / Turmoil Redux (гард
   `tests/console/parliamentGlossary.spec.ts`).
4. **Этот документ** — шаблоны фраз и запреты.

## 4. Шаблоны фраз

- **Требование партии** — ОДНА фраза глоссария, без местоимений (партии разного рода и числа):
  `Требуется: у власти «X» или 2 ваших делегата на резолюции этой партии.`
- **Прочие требования** — `Требуется …`: «Требуется 4 метки Земли», «Требуется быть председателем», «Требуется не менее
  1 влияния», «Требуется лидировать сразу на 2 резолюциях», «Требуется ваш город рядом с океаном». Венера —
  как в базе: «Требование: 10% на шкале Венеры или выше».
- **Pay / Spend**: `Pay` → «заплатите», `Spend` → «потратьте»; «Действие: потратьте 2 сделки с этой карты, чтобы
  добавить 1 делегата на резолюцию.»
- **Триггер-эффект**: деепричастием — «Эффект: разыграв метку Науки (включая эту), положите на эту карту 1 единицу
  данных.»; «Эффект: когда любой игрок …».
- **Оплата ресурсом карты**: «Эффект: при розыгрыше карты с меткой Космоса можно платить мехами с этой карты — по 5 M€
  за каждый.»
- **Старт корпорации**: «Вы начинаете с 38 M€; производство титана — 1.» / «Вы начинаете с 50 M€. Первым действием …»
- **Производство**: «Повысьте своё производство энергии на 3.» (не «уровень производства», не «доход» в новых текстах).
- **Капс оригинала сохраняем** (ЛЮБУЮ, ИГНОРИРУЯ ПРОЧИЕ ОГРАНИЧЕНИЯ) — это часть правила, а не стиль.
- **Журнал**: настоящее время, `${0}` в начале — «${0} возвращает в руку ${1}», «${0} отказывается от эффекта ${1}».

## 5. Запреты (с примерами из аудита 2026-11-01)

| Плохо | Хорошо | Почему |
| --- | --- | --- |
| 1 рычаг | 1 сделка | калька, не ресурс по-русски |
| Торговый хаб | Торговый узел колоний · Венерианский торговый узел (P90) | англицизм — семья «… торговый узел» одна для P46 и P90 |
| Лаборатории фронтира | Передовые лаборатории | калька |
| Наука обитаемости | Наука о поселениях | нелитературно |
| Герметичный порядок на Марсе | Герметический орден Марса | неверный смысл (Hermetic Order) |
| положите 1 данные | положите 1 единицу данных | согласование |
| печатный бонус размещения | бонус размещения его клетки | жаргон разработки |
| не-универсальная метка | метка «Любая» не в счёт | калька + термин проекта |
| Требует, чтобы «Союз» правил … на его резолюции | Требуется: у власти «Союз» … этой партии | шесть вариантов одной фразы, род |
| Изгоните делегата | Снимите делегата | стилистически чуждо |
| Получите 3 титана (карта даёт 2) | Получите 2 титана | ФАКТИЧЕСКАЯ ошибка |
| на ЛЮБУЮ свою карту (EN: ANY card) | на ЛЮБУЮ карту | искажение правила |

Плюс: опечатки («долхно», «эненргии»), «Ученые» без ё в новых текстах, повтор слов («партией партией»), английские
обрывки в RU-значении, литерал кнопки (`LT`, `Y` — см. инвариант 12).

## 6. Названия карт

- Смысл оригинала + звучание печатной локализации; короткое лучше длинного (имя должно влезать на лицо карты в 2 строки).
- Сперва `grep` — у апстрим-карт RU-имя часто уже есть (`ru-card-names-already-exist`).
- Имена корпораций, оставленные в проекте латиницей (`zz_corporation_names.json`), не переводим самовольно.
- **Переименование = один дифф со всем, что ждёт старое имя**: `grep -rn '<старое имя>' tests src` — `CARD_RU` в e2e,
  ожидания текста в спеках, комментарии карт. Гард `tests/console/e2eLiveness.spec.ts` краснеет на мёртвую фразу.

## 7. Когда можно переписывать чужой ключ

Правило локализации запрещает молча менять RU чужого ключа (одна английская строка живёт в логе, подсказке, кнопке).
Аудит перевода — исключение по решению владельца, но только так: `grep` ключа по `src/client`, `src/server`, `tests` →
новый текст подходит ВСЕМ местам → упомянуть в коммите. Не подходит одному — новый, более точный EN-ключ.

## 8. Проверки перед коммитом

1. `npm run make:json` (дубль ключа роняет сборку) и `npm run lint:i18n`.
2. Гарды текста: `tests/console/parliamentGlossary.spec.ts`, `tests/cards/effectCaption.spec.ts` /
   `actionCaption.spec.ts` (компактная подпись ≤ 52 знаков — RU обычно длиннее EN, мерить по RU),
   `tests/cards/cardInformation.spec.ts`, `tests/console/e2eLiveness.spec.ts`.
3. `npm run e2e:affected` — спеки, которые ждут изменённую фразу, и прогон их на боксе.
4. Сверка каждого числа с `description` в файле карты.
5. Глазами: карта на лице, в композере, в подсказке — текст влезает и читается.

- **«with a floater icon» → «со значком аэростата»** (Celestic, P44 — термин поиска `floaterIcon`; не «с аэростатами»: «с аэростатами» = карты, хранящие аэростаты).
