**Оценивается — в этом порядке веса.**
1. **ТАЙЛ ПЛАТИТ — ИЗ СВОЕЙ КЛЕТКИ, НА КАРТУ, ПОСЛЕ ПОСАДКИ.** Два жетона data рождаются у севшего тайла и летят в капсулу
   музея, поднятого из спутника; счётчик тикает на касании, ячейка ПО не раньше; ответ стола (Оптоволокно) — после; у
   соперника — к чипу владельца. Никогда «число изменилось само».
2. **ДОСЬЕ ОТВЕЧАЕТ ЗА КАЖДУЮ КЛЕТКУ ЧЕСТНО.** На чистой клетке — «⚡ +2 [data] → Красный музей» (и ответ стола); у клетки
   рядом с озеленением / океаном — названное НЕТ с причиной («рядом океан»), не пустой блок и не молчание.
3. **ОДИН ПРЕДИКАТ — ТРИ БЛИЗНЕЦА.** Хук, прогноз композера и досье читают одно и то же («свой» · на сетке Марса · город или
   особый тайл · соседи без озеленений и океанов); досье — через флаги контекста, никогда через `Board.isCitySpace(space)`
   до посадки.
4. **Принятые сцены не ломаются:** посадка, бонусы клетки, вода, Ares, волна закона, Дендрарий, перепись Венеры — побайтно;
   у Pets / TR15, если они входят в класс, меняется ТОЛЬКО момент прихода data (A/B).
5. **Полировка** — по чеклисту §7 с названным минимумом сверх P0 (§6).

### Правила чтения (каждое — закрепить спеком карты)
1. **Требование** — Красные (правят или 2 ваших делегата на их резолюции); условие розыгрыша. Эффект работает при любом
   правительстве. Эффект партии, выданный картой (Council Seat TR36 и т. п.), дорогой не считается (FAQ с. 19, чтение TR15).
2. **Розыгрыш ничего не делает**, кроме выкладки карты (держатель data с нулём).
3. **Стреляет только СВОЙ тайл** (`cardOwner === activePlayer`): города и особые тайлы соперников, MarsBot, мировой ход
   резолюции — нет.
4. **Какой тайл:** ГОРОД (`CITY_TILES`: обычный город, Столица, Ocean City, Red City, New Holland) или ОСОБЫЙ тайл
   (`isSpecialTile` — одно определение). Озеленение, океан, опасность Ares — нет. ЯРУС города (Skyscrapers, `stacking`) — тайл
   поставлен (FAQ с. 19, чтение TR15) → стреляет, если клетка подходит. Переезд города (TR14, `moved`) — посадка на новую
   клетку → стреляет по новой клетке (закрепить; если движок читает иначе — назвать).
5. **Где:** НА МАРСЕ — клетка сетки соседства Марса: не `SpaceType.COLONY` (Ганимед, Фобос, Нова-Сити на плитке колонии), не
   внемарсовая нарисованная клетка (Аврора TR27 — вне сетки), не Луна (`BoardType`). ОДИН предикат «на сетке» для хука и
   досье — вынести `onMarsGrid` (`BoardInformationEngine.ts:333`) в `Board` и читать оттуда, не повторять.
6. **Условие клетки — в момент посадки:** ни один сосед (`getAdjacentSpaces`) не несёт тайл-озеленение (`GREENERY_TILES`, Wetlands
   включая) и тайл-океан (`OCEAN_TILES`, Ocean City / Wetlands включая). Пустая океанская клетка, опасность Ares, город соседа,
   особый тайл соседа — не мешают. Сам тайл соседом не является (Ocean City садится НА океан — считаются только соседи).
7. **Выплата: ровно +2 data на ЭТУ карту** (фиксированная цель — автоприменение законно, как у Pets / TR15), под источником
   карты в скоупе `tile-placed`: журнал «эффект сработал», нотификация соперника, прогнозы и статистика — даром. Оптоволокно
   отвечает +2 M€.
8. **ПО = 1 за каждые 2 data здесь** (3 data → 1 ПО); data сюда кладут и другие (Дендрарий, Плутон, Учёные, Medical Database) —
   считаются; атаки на data — общий путь.
9. **Порядок:** тайл сел → бонусы клетки (по движку) → +2 data (один раз на тайл; два тайла одним розыгрышем — Lake Marineris
   не город; у спецтайлов по одному). Данные приходят ПОСЛЕ посадки — никогда до.
10. **Save / load**: счётчик переживает сохранение; хук после загрузки читает поле.
11. **MarsBot** карту не играет; соло — без особенностей.
12. **Журнал**: «${0} added 2 data to ${1}» (существующий ключ выплаты) под корнем размещения; строка ответа стола TR18.

### Решения владельца (по умолчанию — как написано; подтвердить в отчёте, не блокер)
1. RU-имя **«Красный музей»**.
2. Лор RU: **«Нет, у нас нет статуй Карла Маркса. Хватит спрашивать!»**
3. **Сцена «ТАЙЛ ПЛАТИТ» — обобщение сцены TR21, не третий директор:** запись подачи получает причину (`cause: 'adjacent-cities'`

   (океан / озеленение) и число; подсветка мешающих клеток на поле — НЕ в этой задаче (тона `reward` / `score` значат «платит /
   считает»; новый тон — решение владельца, строка реестра с кадром).
6. **Прогноз композера для карты, ставящей город / спецтайл** — форма Mining Guild: без чисел, с `note` «зависит от клетки —
   досье покажет». Форма с чипом «+2 · если рядом нет озеленения / океана» — вариант для владельца, не делать.
7. **Выплата — синхронно внутри хука** (как TR24: `addResourceTo` + запись), не отложенно (Pets / TR15 откладывают
   `AddResourcesToCard`): у выплаты нет вопроса и фиксированная цель. Если очередь требует откладывания (вопрос между посадкой и
   выплатой) — отложить И записать в `andThen`, сказать.
