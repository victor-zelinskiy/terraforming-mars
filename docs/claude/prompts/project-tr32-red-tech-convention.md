**Оценивается — в этом порядке веса.**
1. **ОДИН ОПИСАТЕЛЬ ФИЛЬТРА — ВЕЗДЕ.** `DrawCard` получает отрицательный фильтр (класс, не bespoke), и один серверный описатель

   текст лица, итог reveal и лоток. Ни одного текста, собранного клиентом из догадки.
2. **ВЕРДИКТ С ПРИЧИНОЙ.** Каждая сброшенная карта в лотке несёт метку, которая её отсеяла (сервер называет, клиент
   подсвечивает печатную метку лица); итог reveal читается «вскрыто 6 · взято 3 · сброшено 3 — метки растений, бактерий,
   животных». Поток сцены (отрыв → инспект → вердикт → лоток / hold) — язык семейства, побайтно (A/B Acquired Space Agency).
3. **ТРИ КАРТЫ — ТРИ ОБЪЕКТА, В РУКЕ.** Добор розыгрыша живёт в workspace руки (`console-play-draw-embed`): карты сходят с колоды

   тикает на каждом касании; workspace уходит после последнего.
4. **Исчерпание колоды — названо**, не молчит и не падает; перетасовка сброса — без зацикливания.
5. **Полировка** — по чеклисту §7 с названным минимумом сверх P0 (§6).

## 1. Блок A · сервер

### A1 · DSL — отрицательный фильтр (класс)
`Behavior.DrawCard` + `withoutTags?: ReadonlyArray<Tag>` («discard cards WITH any of these tags»); `Executor` передаёт его в
`player.drawCard(n, {…, withoutTags, source})` (расширить `DrawOptions`, не собирать замыкание в исполнителе — описатель должен
доехать до reveal); `DrawCards.execute` отсеивает `withoutTags.some((t) => player.tags.cardHasTag(card, t))` — тот же читатель,
что у `tag`; `keepAll` считает фильтр структурным (`DREW_VERBOSE`). Декларативный превью (`actionPreview.ts:449–457`) и
`drawGain` получают **описатель поиска** `ActionEffect.search?: DrawSearchModel` (решение 5) — чип не меняет форму, только
знает правило; структурный текст (`buildCardInformation.ts:535–541`) печатает фильтры САМ («Reveal cards until 3 without a
plant, microbe or animal tag; take them, discard the rest.» / «Draw a Space card.») вместо заметки курирования — проверить, что
TR05 / Pharmacy Union / Deep Space Operations не меняют своих текстов без причины (гард `cardInformation`).

### A2 · Reveal с причиной (класс)
`CardDrawRevealModel.search?: DrawSearchModel`; `CardDrawRevealStep.failedTags?: ReadonlyArray<Tag>` — метки, отсеявшие карту
(считает `DrawCards.execute` в `onReveal`, по описателю; у положительного фильтра — пусто, причина = «нет метки X» из описателя).
`enqueueCardDrawReveal` несёт описатель всегда, когда он есть у поиска (даже если ничего не сброшено — итог называет правило), и
`sequence` — как сегодня, только при сбросах.

### A3 · Исчерпание — названо ключом
`Deck.drawByConditionOrThrow:169–171` пишет шаблонную строку без ключа i18n → заменить на ключ («Searched the whole ${0} deck —
no more matching cards») с RU; `DrawCards` отмечает в reveal `exhausted: true` → итог «колода вскрыта до конца — чистых карт: N»
(решение 7). Спек: колода из 4 карт с 1 чистой → 1 карта в руке, лог ключом, reveal `exhausted`, без исключения; стопка добора
пуста, сброс полон → перетасовка посреди поиска, отсев повторный, конечность.
