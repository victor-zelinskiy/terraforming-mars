**A1 · Карта — сырой апстрим, и каждый гард уйдёт в красное, как только строка покинет hold-back.** `BoardOfDirectors.ts` — `PreludeCard implements IActionCard` с рукописными `canAct`/`action`; хуков `actionUnavailableReason` / `actionPreview` / `actionFutility` / `infoText` нет; маркера на `SelectCard` нет. **A2 · Без маркера — общий браузер карт, отдельной лентой, с оплатой ВТОРЫМ вопросом.** Голый `SelectCard` → `consoleTaskRouter.ts:850` → `cardSelect` (легаси-браузер); claim «ДЕЙСТВИЙ КАРТ» его не присваивает (`branchOutcomeClaimPlan` даёт `pick` только под чип `cards` / `revealSplit`) → промпт встаёт ОТДЕЛЬНОЙ ЛЕНТОЙ поверх workspace — модалка, которая «прибыла».
