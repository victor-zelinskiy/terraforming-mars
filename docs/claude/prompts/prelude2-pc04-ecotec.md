## Диагноз (файл:строка на `2a56e791f6`; A1–A6 — факты кода, A7–A10 — гипотезы: подтвердить кадрами и зондом «ДО» ПЕРВЫМ делом)

**A1 · Вопрос без маркеров.** `OrOptions` + `SelectCard` + `SelectOption` (`:51–65`) собраны голыми: нет `markChoiceContext` (консоль не знает, ЧЬЯ это карта спрашивает и почему — а по заголовку узнавать запрещено), нет метаданных опций (исход «+1 растение» не чип), у пика нет `resourceGainPrompt` (кандидат без «было → станет», без ПО, без роли держателя; приём ресурса картой не взводится). `promptMarkerGuard` покраснеет в момент снятия строки hold-back.

**A2 · Кандидаты мимо общего предиката и не вовремя.** `player.getResourceCards(MICROBE)` (`:43`) вместо `AddResourcesToCard.getCards()` — второй ответ на вопрос «кто держит бактерии» рядом с общим; список взят ОДИН раз при входе в `process`, вне отложенных замыканий — все N вопросов одного розыгрыша несут снимок, а не стол на момент вопроса.

**A3 · Нет двойника прогноза.** «Сработает» молчит на каждой био-карте в руке; вопрос не пред-отвечается в композере и встаёт ПОСЛЕ нажатия, посреди розыгрыша; `effectForecastCoverage` красный.

**A4 · Текст и рендер расходятся со сканом.** EN-текст эффекта не содержит «including these 2» — правило, которое платит 2 растения на старте, на лице не названо; причина — три метки подряд без косых (читается «все три»); исход — косая вместо печатного «OR».

**A5 · RU.** «1 микроб» при «метку бактерий» в той же фразе — два слова на одно понятие; «включая эти 2» нет.

**A6 · Источник.** `stock.add` и `addResourceTo` без `from` (`:45`, `:57`, `:62`). ⚠ НЕ утверждать, что запись без него теряет карту: хук идёт внутри скоупа эффекта (`Player.ts:1879–1881`) — выяснить зондом (`game.cardReactions`, строка журнала), записать, что `from` даёт на деле; ставить его по грамматике двойника.

**A7 · (ОБЛАСТЬ) Серия живьём — повтор без счёта и, вероятно, с миганием.** Сервер откладывает N ОДИНАКОВЫХ вопросов (`for (let i = 0; i < count; i++) player.defer(…)`) и не сообщает ни индекса, ни общего числа. На живой дороге (вопрос не пред-отвечен: розыгрыш без композера, отказанный ответ, `onNonCardTagAdded`) игрок отвечает — и видит тот же вопрос снова: ни «2 из 3», ни признака, что первый ответ принят. Допуск вопроса держит присутствие по `promptId` — новый вопрос серии это новое присутствие: поверхность, скорее всего, уходит и встаёт заново между k и k + 1 («модалка мигает»). Тот же класс уже живёт у Viral Enhancers (`ViralEnhancers.ts:63–65`) — контроль класса.

**A8 · (ОБЛАСТЬ) Серия в композере — N одинаковых строк.** Три факта `asks` одной корпорации (`id: tag-0…2`) дают три неразличимые строки; после ответа на строку k через вложенный выбор карты курсор, вероятно, возвращается на неё же; плита коммита при неотвеченных строках не говорит, сколько осталось.

**A9 · (доказать, не строить) Вложенный выбор карты СТОЛА внутри вопроса стола.** Опция «бактерия» — пик среди разыгранных карт: дверь `orOptionDoor` ведёт во встроенный шаг цели. Проверить на Ecotec три вещи, каждая — готовый класс: единственный держатель посеян, ПОКАЗАН и помечен «единственная цель» (T14); разыгрываемая карта, сама хранящая бактерии (Tardigrades без других держателей), стоит кандидатом «ЭТА КАРТА» (`cardBeingPlayed`, `played-target-self.md`) — и прогноз тогда ОБЯЗАН спрашивать, а не обещать растение; ответ-бактерия на карту стола виден из «КАРТЫ В РУКЕ» (приём ресурса картой / стадия «РАЗЫГРАНО»).

**A10 · (доказать, не строить) Старт.** «Включая эти 2»: на вскрытии корпорации хук платит 2 растения за собственные метки. Прецедент есть (TR84) — доказать стендом: «Сработает: +2 растения» на карточке очереди ДО нажатия, после — растения 0 → 2 на касаниях, рассказано один раз.

## Правила карты (пинятся спеком; не переоткрывать)

1. **Старт:** 42 M€, производство растений +1; метки БАКТЕРИЯ и РАСТЕНИЕ. **«Включая эти 2»:** розыгрыш самой корпорации — две био-метки, два срабатывания: на старте держателей бактерий нет → +2 растения.
2. **«Био-метка»** = печатная метка БАКТЕРИИ, РАСТЕНИЯ или ЖИВОТНОГО на разыгранной карте (`card.tags`). Одно срабатывание за КАЖДУЮ такую метку: карта с двумя — два, с тремя — три. Джокер не считается. Событие с био-меткой считается (метка сыграна).
3. **«Когда ВЫ разыгрываете»:** только свои розыгрыши, любой дорогой через `playCard`; чужая карта и флип бота — нет.
4. **Каждое срабатывание — отдельное решение:** 1 растение ИЛИ 1 бактерия на ЛЮБУЮ свою карту, способную их держать (сама разыгранная — тоже, если держит). Решения одного розыгрыша независимы: можно два растения и бактерию, можно три бактерии на одну карту.
5. **Нет держателя — нет вопроса:** растение приходит сразу (ветка одна, скрытой цели нет). Есть хотя бы один держатель — вопрос задаётся ВСЕГДА, даже с единственным кандидатом.
6. **Не-карточная метка растения** (`onNonCardTagAdded`) — одно срабатывание по тем же правилам; в скоупе её сегодня ничто не добавляет (пин спеком, без стенда).
7. **MarsBot:** человеческая Ecotec и бот-двойник C40 на одном столе не встречаются (коллизия по `original`); двойник не трогается. Вторая корпорация (Merger): эффект с момента розыгрыша, свои две метки тогда задают ДВА вопроса, если на столе уже есть держатель.
