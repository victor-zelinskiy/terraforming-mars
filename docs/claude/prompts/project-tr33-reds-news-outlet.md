§ TR33, реестр раздел J). **Коммиты полировки** — отдельно, по одному на находку (`Polish (TR33 walk): PL-### — …`), каждый с
«до / после» и гардом. Перед каждым: `npm run lint`, `npm run build:test`, `npm run make:cards`, `npm run make:json`; перед
визуальной проверкой — `npm run make:css` + `npm run build:server`; юниты — последовательно. **Не пушить.** «Ждёт владельца» —
одним батчем после P0 (память `owner-batches-pending-polish-decisions`).
Гочи: у `turmoilReduxExpansion` в `testGame` нужен `coloniesExtension: true`; старый бандл новую карту в руке не рисует — кадры
руки только на своей сборке; `python3` — заглушка Store; `eqeqeq` без исключения для null; bash heredoc с длинным RU-текстом
ломается — Write; `\b` не видит кириллицу; чужой ханк в `lore_texts.json` — §0.
**В отчёте:** что встало само (всё) и что закрепили спеком; кадры §5 (включая стол Учёных); что напечатали гарды; новые ключи;
подтверждение решений 1–5; арт — получен или нет. **Раздел «ПОЛИРОВКА»** по §7 — с замером «сколько ушло на карту, сколько на
маршрут». **Явно — всё, что не получилось сделать, и почему.**

## 8. Нельзя
`renderData` / `vpText` у лица без графики (второй источник правила); свой подсчёт меток в файле карты (только `{tag, per}`);
учёт дикой метки / R&D Funding / событий в ПО; e2e «на ещё одну карту»; стейджить чужой `"X87"`; литерал имени карты в
`src/client/**`; переписывание чужого RU (PL-031 — новая таблица имён и новые ключи, если слово меняется у чужих карт — решение
владельца); `compatibility`. В полировке — всё, что запрещает чеклист §7. Трогать незакоммиченные файлы соседа, `shardPlan.json`.
Пуш и красные коммиты.
