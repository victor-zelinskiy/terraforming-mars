### Правила чтения (каждое — закрепить спеком)
1. **Требование** — `requirements: {party: PartyName.UNITY}` (класс TR15; плашка «Союза» уже есть — TR22).
2. **При розыгрыше**: +1 data на ЭТУ карту за каждую **колонию в игре любого игрока** — колония = КУБ на плитке колонии
   (два куба на тайле = 2), считаются все места, включая MarsBot. Это существующий счётчик: `{colonies: {colonies: {}},
   all: true}` (`Counter.ts:199–207` — `colony.colonies.length`), декларативно `behavior.addResources`. Город «Нова-Сити»
   на плитке колонии — НЕ колония (он живёт в `IColony.tiles`), неактивная плитка без кубов даёт 0. Колоний в игре нет →
   0 data, карта играбельна: это правило, не потеря (ни предупреждения, ни события пропуска).
3. **Действие**: потратить 2 data С ЭТОЙ карты (`spend: {resourcesHere: 2}`) → получить **бонус колонии за КАЖДУЮ свою
   колонию**. «Бонус колонии» — третья строка плитки (`metadata.colony`, `IColony.colonyBonusGrant`): то, что получает
   владелец куба, когда на плитке торгует ДРУГОЙ. Не доход торговли и не бонус постройки (ловушка RX07 §9: Миранда платит
   КАРТУ, а не животное).
4. **По кубу, без слияния** (решение №3): два своих куба на тайле — бонус дважды, каждый разрешается отдельно и целиком
   (закон движка — `Colony.ts:469–474`). Слияние повторов («одна раскладка k единиц») — закон РЕЗОЛЮЦИИ (×k), сюда не
   переносить.
5. **Порядок выплаты = порядок очереди движка, и реестр показывает именно его**: сначала бонусы без вопроса (запас,
   производство) в порядке стола `game.colonies`, затем бонусы с шагом (ресурс на карту, добор, пара «взять → сбросить») в
   порядке стола. Так уже работает `player.defer(() => colony.giveColonyBonus(...))` на каждый куб: лямбды мутируют сразу, а
   их отложенные шаги встают за оставшимися лямбдами. Порядок Titania → … → Leavitt из `ProductiveOutpost` сохранить.
6. **Действие недоступно без своих колоний** (решение №4) — причина «Колоний нет» (ключ `You have no colonies` УЖЕ есть).
   Порядок причин (одна на отказ): мало data на карте → нет колоний. Колонии есть, но часть бонусов некуда получить
   (нет держателя аэростатов) — действие доступно, пропуск НАЗВАН с величиной до нажатия и записан после
   (`recordSkippedEffect` общего шага).
7. **Никакого авто-выбора**: единственный держатель у бонуса «ресурс на карту» — всё равно шаг композера с «было →
   станет» (`autoSelect: false` + `previewSelectCard()`), один шаг на куб.
8. **Пара Плутона / Венеры Redux** («взять 1, затем сбросить 1») — по паре на куб, следующая карта не видна до сброса
   (`sealCardDrawReveal`), сброс не предсобирается (скрытая информация) — он паркует хвост батча и отпускает его после ответа.
9. Действие — раз в поколение, как любое действие синей карты. Data на карте — обычный ресурс: её кладут TR01, Redux-Плутон,
   TR21 и т. д.; платёжной единицей она не является.
10. **Реакции** — ничего не программировать, закрепить спеком: розыгрыш карты — это метка Науки (TR05 «Векторные
    вычисления» +2 data себе, Olympus Conference, Mars University) и N data на карту (TR18 «Марсианское оптоволокно» +N M€).
11. Журнал: розыгрыш — одна строка с ПРИЧИНОЙ («+5 data · за 5 колоний в игре», член `basis` события — TR21); действие —
    корень «действие карты», под ним строки бонусов с источником-КОЛОНИЕЙ (уже так: `events.withSource({kind: 'colony'})`,
    `Colony.ts:510–513`).
12. MarsBot карту не играет; его кубы считаются при розыгрыше (правило 2).

### A3 · Атрибуция: бонус колонии, выплаченный КАРТОЙ, называет карту
Один необязательный член, протянутый через `IColony.giveColonyBonus` (сегодня позиционные `isGiveColonyBonus, ordinal,
