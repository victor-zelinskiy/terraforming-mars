## 4. КАРТОЧКА «ИТОГИ» — ВЕДОМОСТЬ (решение 4) — композиция
**Цель (владелец, 2026-10-30):** «максимально понятная премиальная компактная подача сути того, что игроки получили; всё помещается и использует максимум
свободного пространства». Карточка НИКОГДА не скроллит и НИКОГДА не выпускает содержимое за свои рамки — на любом наборе мест и записей, на трёх профилях.

**4.1 Модель итогов — чистая, `parliamentResultsModel.ts` → `resultsTotalsOf(parts)`.** Ряд места печатает ИТОГИ ПО ЕДИНИЦАМ, а не записи:
- слияние: один вид ∧ одна единица ∧ склад / производство ∧ (ресурс карты + карта-получатель); добор и сброс НЕ сливаются друг с другом («+3 [карта]» и
  «сброшено 3»); параметр, тайл, ярус, шаг Карьеры, РТ — ОБЪЕКТЫ, каждый своим токеном; ответ правящей партии ВЛИВАЕТСЯ в итог своей единицы (игрок получил
  M€ — это одно число), но несёт метку источника; налог закона нетится в свою единицу (итог M€ = ЧИСТЫЙ: «−3 [M€]»), `row.net` уходит в итог;
- каждый итог несёт `sources` — ГДЕ взялось: `{colony, times}` (планета тайла ×k), `{party}` (эмблема ответа), `{law}` (закон), `{winner}` (корона) — для меток;
- пропуск остаётся пропуском (название + причина сервера) — одной строкой, без плиты;
- **инвариант 4 спеком**: Σ итогов по единице = Σ записей по единице; ни одна запись не потеряна (в т. ч. пропуск); корпус — «Колониальные дела» с парами Плутона,
  Конкурс мохола с ответом Зелёных (кадр 1), бюджет с налогом, бот-победитель (кадр 2), закон, который не платит никому.

**4.2 Компоновка.** Три зоны по РОЛЯМ, ширины РЕШАЮТСЯ, а не задаются `fr`:

  печатей «старая › новая ПРАВИТ · У ВСЕХ» как сейчас (закон PL-112 — не трогать).
- **ВЫПЛАТЫ** (центр, главное тело — забирает всё, что не нужно другим зонам) — ВЕДОМОСТЬ: ОДНА СТРОКА НА МЕСТО, строки друг под другом, равной высоты
  (`grid-template-rows: repeat(n, minmax(0, 1fr))`), порядок — `summary.outcomes` (тот же, что сейчас). Строка — горизонтальная плита из двух ячеек:
  - **кто**: точка места · имя (НИКОГДА не режется — ширина ячейки решается по самому длинному имени) · под именем — роль словом с короной «ПОБЕДИТЕЛЬ ГОЛОСОВАНИЯ»
    (своя строка, никогда `margin-left: auto` рядом с именем); место смотрящего — циановый inset-кант, победитель — золотой inset-кант (есть);
  - **итоги**: токены `ConsoleSitTotals` — крупное число + значок единицы в языке рельса (рамка производства, знак, ресурс на карту — значок + мини-имя карты),
    параметр «−26 → −22 °C · РТ +2», тайл; под токенами — ОДНА тихая строка меток источников (ТОЛЬКО значки: планеты тайлов с «×3», эмблема партии, корона) —
    без текста; пропуск — одна строка «Пропущено · эффект резолюции — влияния нет» на месте токенов.

- **СЛЕДУЮЩЕЕ ГОЛОСОВАНИЕ** (справа) — существует, только когда ему есть что сказать: свежие резолюции — лицами РЕШЁННОГО размера (минимум — подпись лица
