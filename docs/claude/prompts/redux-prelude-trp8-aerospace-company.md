## Диагноз (подтверждён файл:строка на `2bb9b7c89d`; перепроверить на своём HEAD)
1. **Класс карты — апстримный, ДАРОМ.** `ActivePreludeCard` (`prelude2/`) — ровно «прелюдия + `action`-behavior»: `canAct`/`action` через Executor, превью `declarative` выводится из `card.actionBehavior` (`actionPreview.ts:104`) независимо от базы, причина недоступности — `actionUnavailableReasons.ts:153` («No card to add the resource to», существующий ключ). Импорт через границу каталога (`../prelude2/ActivePreludeCard`) — как TRP1 импортирует `../prelude/PreludeCard`. `cardReasonConsistency.spec` эту базу уже перечисляет. Розыгрыш — ПУСТОЙ `behavior` (ничего не объявлять): прелюдия ложится на стол с двумя метками; `unplayableReasons` для карты без behavior молчит — прелюдия всегда разыгрываема (правило 2 ниже).
2. **Действие — ОДНА декларация над СПИСКОМ видов, и список ВЕЗДЕ ниже DSL уже есть.** `AddResourcesToCard` принимает `CardResource | ReadonlyArray<CardResource>` (`:195`), `holders()` строит ОБЪЕДИНЕНИЕ держателей по списку (`:225–260`), модель пика несёт `cardResources` + `cardResourceByCard` (`PlayerInputModel.ts:1079, :1086`), консоль знает вид ресурса каждой карты стола (`consoleCardActions.ts:1266`) и умеет читать несколько иконок исхода (`holderGainOutcomeIcons`). Не хватает ОДНОГО: `AddResource.type?: CardResource` (`Behavior.ts:211`) — одиночный. Расширить до `CardResource | ReadonlyArray<CardResource>` и провести по читателям, которые его трогают НЕ как прозрачное значение: `addToCardStep(player, resource: CardResource | undefined, …)` (`actionPreviews.ts:378` — сигнатура), чип превью `cardResourceIcon(a.type)` (`actionPreview.ts:611` — решение 2), ходок `countableBasis`/`stepsForBehavior` (проверить, что шаг цели для списка не теряет `cardResourceByCard`). Executor `:240/:635`, причины `:153`, `unplayableReasons:531`, `addAnyCardCandidates:367` — прокидывают `type` как есть (типизацию проверит `tsc`). Декларация карты: `action: {addResourcesToAnyCard: {type: [CardResource.MECH, CardResource.FIGHTER], count: 1, mustHaveCard: true}}` — `mustHaveCard`, потому что это ДЕЙСТВИЕ: без держателя оно недоступно С ПРИЧИНОЙ (инвариант 2), а не «нажал — ничего не произошло» (память `futile-actions-iteration`). Бесподобное `action()` с двумя `AddResourcesToCard` или `OrOptions` «мех / истребитель» — НЕ писать (решение 1).
3. **Гоча ① — заголовок пика для списка.** `AddResourcesToCard.ts:349`: `message('Select a card — ${1}: +${0}', … this.resourceType || 'resources')` — для списка видов `resourceType` undefined → в заголовок уходит сырое слово «resources» (не переводится, не называет видов). Исправить В ЭТОМ ОДНОМ МЕСТЕ: для списка — заголовок, называющий виды после тире («Select a card — mech or fighter: +1» — новый ключ с RU «Выберите карту — мех или истребитель: +1»; форма «после тире» — закон TR48, существительное не склоняется внутри фразы). Medical Database не ловил этого, потому что идёт через `AddResourcesToCards` со своим заголовком.
4. **Первая прелюдия с действием НА ПРЕМИУМ-ЛИЦЕ и в «Действиях карт» — проверить, не строить.** `getPlayableActionCards` обходит `playedCards`, где лежат прелюдии, — плитка появится сама; лицо плитки — тема прелюдии (магента) с блоком `b.action(...)`: такой комбинации в скоупе не рисовали (prelude2 — фронтир). Кадр 4K обязателен: блок действия внутри магентовой рамки, кикер «ПРЕЛЮДИЯ», подпись `action-short`. Без держателя на столе плитка СТОИТ отключённой с причиной «нет карты, куда положить» (инвариант 2; `potentialAvailability` / превью действий читают `actionUnavailableReason`) — проверить, что список действий вообще показывает прелюдию с недоступным действием, а не только `getPlayableActionCards`.
5. **Старт — прелюдия БЕЗ эффекта розыгрыша.** Стартовая очередь читает `cardPlayPreview`/эффекты карты для плашки и статус-рейла церемонии (TR82: строка «Сработает»); у TRP8 эффектов НОЛЬ. Проверить ТРИ вещи: (а) «burn gate» (`consoleStart.ts:475–541`, «СГОРИТ» — прелюдия, которую нельзя разыграть, превращается в 15 M€) НЕ срабатывает — TRP8 всегда разыгрываема; (б) рейл не рисует предупреждение «без эффекта» / «ничего не произойдёт» — пустой список эффектов у прелюдии с действием — норма; (в) полка «РАЗЫГРАНО» принимает карту без скачка (PL-1105…1107 — шаг 1 надёжности старта). Статус — ТОЛЬКО ДЕЛЬТА (память `no-face-restatement`): рейл не пересказывает лицо, строки «Действие станет доступно» не выдумывать (решение 4).
6. **Метки на прелюдии — впервые в наборе.** TRP1 меток не имела. Космос + Здание считаются везде, где считаются метки прелюдий (вехи/награды, Proteus `matchingPreludeTags`: TRP8 рядом с Mining Operations → 1 data за Здание; рядом с Orbital Construction Yard → 1 data за Космос). Платёжных последствий нет (у прелюдии нет цены): EVA/TR17/Arwind не касаются.
7. **Кандидаты — объединение двух семей, до 17 карт на полном столе.** Шаг «КУДА» над восемью держателями 4K держал впритык (TR85 решение 3); над мехами И истребителями вместе может не держать. Стенд семьи — РЕАЛИСТИЧНЫЙ смешанный стол (4 меха + 4 истребителя — известная ширина восьми, решение 5), а не все семнадцать; кадр — решение 3.
8. **Что НЕ меняется.** `AddResourcesToCard` (кроме заголовка ①), модель пика, композер, полёты ресурсов на миниатюру (Veynon D — тот же полёт), `holderRoles` (TRP8 ничего не держит — ни чипа спутника, ни роли), MarsBot (прелюдии не раздаются), сериализация (на карте нет состояния; `actionsThisGeneration` — общий флаг).
