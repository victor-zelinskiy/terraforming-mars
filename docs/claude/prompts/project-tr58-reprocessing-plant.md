### 2.А Одна грамматика курсора (класс, не 15 правок)

### 2.Б Фокус по умолчанию ПРИХОДИТ (решение 6)
- **Поверхность садится без фокуса, курсор приходит тактом.** Общий механизм «прихода» — одна функция / композабл (`cursorArrival`), которую каждая поверхность зовёт в СВОЙ момент готовности: рука —
  кадр после передачи; ряды стейджа (добор, ревил, выбор из колоды, драфт, задача хоста) — после последнего касания; «Действия карт», колонии, стандартные проекты, композеры, Парламент — после входа
  поверхности (surface motion `settled`); шаг цели — после раскрытия шага. До прихода — поза покоя (нет кольца, нет подъёма, нет `z-index`), курсор ЛОГИЧЕСКИ уже стоит (ввод работает, бар верен,
  первое нажатие во время прихода — сразу шаг, без ожидания конца анимации). Reduced motion — курсор без такта.
- **Рука.** Альбом монтируется с карточкой без позы фокуса (класс позы — только после прихода), цели полёта снимаются с ПОКОЯЩЕГОСЯ слота (без 1.035) и перемеряются перед касанием (раскладка
  заморожена на время полёта; поздний перемер / смена индекса во время полёта — переприцел, не «посадка в старое место»); копия ТОЖДЕСТВЕННА покоящемуся слоту (та же мятная нить «играбельна», тот же
  блокер-чип, та же тень) — передача «показать, потом убрать на СЛЕДУЮЩЕМ кадре» без кросс-фейда (`HANDOFF_MS` уходит или становится 0); `flightVisuals` живут до снятия копий; затем — приход курсора
  на первую карту. Свидетель: в кадре передачи разница пикселей зоны карты ≈ 0; приход — кольцо 0 → полное за ≥ 3 сэмпла, подъём синхронно.
- **Ряды стейджа** — `opacity` в переходе; `--has-focus` (соседи 0.8) включается вместе с приходом, не на передаче (или затемнение — слоем, переходом); `finishDeal` (`ConsoleDeckPick.vue:644–662`) —
  фит ДО снятия копий, никогда в кадре прихода; в сцене добора — приход после конца затухания копий.
- **Композеры** — один посев фокуса (никакой пересадки на `$nextTick`, `ConsoleActionComposer.vue:3537`); рефетч превью той же формы не сбрасывает курсор (как `samePreviewShape` у розыгрыша);
  стандартные проекты — посев до первого рендера (не индекс прошлого визита + пересадка).

### 2.В Шаг курсора — уход и приход одной фразой
- Кольцо уходит с прежней карты и приходит на новую НА ОДНИХ часах с подъёмом (перекрытие, без кадра «две карты в кольце на полную» и без кадра «ни одной»); `z-index` уходящей карты держится до
  конца её спуска (дискретный переход с задержкой / класс `--leaving`), чтобы она не ныряла под соседа увеличенной.
- **Слежение прокруткой** (решение 7) — одна функция `ConsoleScrollArea` с плавной прокруткой на токенах; `scrollIntoView` удалить (колонии, задача хоста, ревил); мерить ПОКОЯЩУЮСЯ коробку

## 8. Нельзя
- Чинить фокус по одной поверхности своим числом (новые 150 / 160 / 260 мс) — только токен и миксин; кольцо на одном элементе, переход на другом; несовместимые списки теней с «переходом».
- Фокус, рождённый под копией и проявленный вместе с картой; кросс-фейд двух разных картинок одной карты; копия, отличная от покоящегося слота; цель полёта, снятая с позы фокуса.
- `scrollIntoView`; мгновенный `scrollTop` при слежении; прокрутка, вызванная трансформом фокуса; перефит (`zoom`) в кадре прихода.
- Задерживать ВВОД ради анимации прихода (курсор логически стоит сразу; первое нажатие — сразу шаг); `setTimeout` вместо сигнала готовности поверхности (холд / событие); rAF в пробниках.
- `filter` / `text-shadow` на состоянии; `transition: all`; анимация `width` / `height` / `top` / `left`; бесконечная петля не на compositor; `title`-атрибут; литерал кнопки.
- Детектировать ветку / шаг по заголовку; авто-выбор единственного держателя; вопрос оплаты тепла после коммита.
- Ломать селекторы стендов без перевода в том же диффе; полный regen фикстур; `git stash`; bare `git push`; переписывать RU чужих ключей; трогать незакоммиченные файлы сессии TR57.
