## Правила карты (пинятся спеком; не переоткрывать)

1. **Старт:** 31 M€; производство энергии +1 и M€ +2; меток нет.
2. **Добор на вскрытии — ПОИСК:** вскрывать колоду до первой карты БЕЗ ЕДИНОЙ ПЕЧАТНОЙ МЕТКИ, не являющейся событием; она идёт в руку, вскрытые — в сброс. Карта с одной лишь меткой-джокером правилу поиска НЕ подходит (метка напечатана) — так у апстрима, и апстримный спек это пинит (`:26–27`).
3. **«Сколько меток у карты» для ЭФФЕКТА:** печатные метки, кроме джокера, плюс 1, если карта — событие («Event tag is a tag», «Wild tag is not a tag» — апстримные `it`). Ноль → +4 M€; ровно один → +1 M€; два и больше → ничего.
4. **Два понятия «без меток» — и оба названы.** ПОИСК: нет печатных меток вовсе, событие не подходит. ЭФФЕКТ и СЧЁТЧИК рельса (`numberOfCardsWithNoTags`): джокер меткой не считается, событие не подходит. Расходятся они только на карте с одним джокером: поиск её отбрасывает, розыгрыш платит +4. Не сводить в одно правило — оба закреплены апстримом; назвать разницу в шапке файла и в спеке.
5. **«Включая эту»:** собственный розыгрыш корпорации — карта без меток → +4 M€: фактический старт 35 M€ (апстрим `:25`).
6. **«Когда ВЫ разыгрываете»:** только свои розыгрыши, любой дорогой через `playCard`; чужая карта и флип бота — нет. Выплата приходит ПОСЛЕ вопросов розыгрыша (отложена) — ею нельзя оплатить породившую её карту.
7. **MarsBot:** человеческая Sagitta и бот-двойник C44 на одном столе не встречаются (коллизия по `original`); двойник не трогается. Вторая корпорация (Merger): её розыгрыш — тоже карта без меток (+4) и тоже поиск.
