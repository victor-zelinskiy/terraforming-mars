## Диагноз (подтверждён файл:строка на `9b97a04628`; перепроверить на своём HEAD)
1. **Live-хук ЕСТЬ, форкаст его НЕ ЗЕРКАЛИТ.** `onIncreaseTerraformRatingByAnyPlayer` стреляет по всем столам из единственной двери `increaseTerraformRating` — Lotus получает хук даром (`cardOwner.id === player.id` → `player.addResourceTo(this, {qty: steps, log: true})`; `steps` — сразу N данных за один вызов на N шагов). Нужен **ПАСС РЕЙТИНГА**: ОДИН хелпер `ratingStepsOf(grants, effects, player)` (= `Σ tr` + `Σ global.steps` + `extra`-бонусы треков − вето; ВЫНЕСТИ из `partyFacts`, Зелёные читают его же), `ratingRaiseFacts(recipient, active, card, grants, ctx, inherit)` по образцу `scaleRaiseFacts` — ОДИН грант `{kind:'tr', amount}` каждому реактору хука на КАЖДОМ столе (`ctx.world` — у мирового хода raiser'а нет), канал `'tr-increase'`, `unknownFor` без двойника; пара `{live: 'onIncreaseTerraformRatingByAnyPlayer', forecast: 'grantForecast'}`; certainty/timing — наследуются от того, что даёт РТ (явный `tr`-чип розыгрыша — `exact`/после карты; океан посадкой — `deferred`/после посадки — как каскад `inherit`).
