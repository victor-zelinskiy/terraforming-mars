**Задача из двух частей** (чеклист §7): **≈ 80 % — карта** (§1–§5), **≈ 20 % — полировка по пути** (§6). Особенность карты:
она **ничего не спрашивает** — ни резолюции, ни партии, ни цели — и при этом делает ТРИ вещи сразу, две из которых меняют
политику стола (голоса на двух резолюциях — может смениться победитель голосования; поддержка двух партий — лимит 3), а третья
(M€ по числу нейтралов в игре) — ЧИСЛО, которое игрок не держит в голове. Владелец просил «хорошую подачу»: карта должна
ОБЪЯСНИТЬ себя до нажатия (кто получит нейтрала и что это меняет; сколько нейтралов будет в игре и почему столько M€) и
ПОКАЗАТЬ себя после (кубы садятся по одному, пересчёт идёт по столу, монета рождается из счёта). Образец формы — TR04: розыгрыш =
исход, Парламент поднимается ВНУТРЬ зоны руки, ничего не выбирается, крошка только растёт, уход одной поверхностью.

**Оценивается — в этом порядке веса.**
1. **ДО НАЖАТИЯ КОМПОЗЕР ГОВОРИТ ВСЁ, ЧИСЛАМИ СЕРВЕРА.** Каждая резолюция-получатель названа с «голосов N → N + 1» и
   политическим следствием («становится победителем голосования» / «остаётся» / «ничья — ближе к правительству»); каждая область —
   «+1 (1 → 2 из 3)» или названный ноль («+0 · область заполнена», «+0 · нейтральных не осталось»); партия без резолюции на
   столе — названный ноль спокойным регистром; итог — «нейтральных в игре 11 → 14 → +14 M€». Ни одного числа, выведенного
   клиентом.
2. **ПОСЛЕ НАЖАТИЯ — ТРИ ТАКТА НА ОДНОЙ ПОЗЕ, ПО ПЕЧАТНОМУ ПОРЯДКУ.** ГОЛОСА (куб из пула → лента резолюции, счётчик голосов и
   маркер победителя — на касании), ПОДДЕРЖКА (куб из пула → место плашки; полная область ЧИТАЕТСЯ, а не молчит), ПЕРЕСЧЁТ
   (каждый нейтрал в игре отмечается по очереди, счётчик растёт тик за тиком) → ОДНА монета «+N M€» рождается ИЗ СЧЁТА и летит на
   рельс (тик на касании) → чтение → уход одной поверхностью. Ничего не тикает раньше своей причины; пул убывает на отрыве.
3. **ОДИН ПЛАН — ДВЕ ЧИТКИ.** Превью и розыгрыш спрашивают одну функцию плана (кому, сколько, что срезано, сколько в игре); ни
   одного второго счёта; писатели стола — только существующие (`addNeutralVote`, `addPopularSupport`); названные пропуски по
   `SUPPORT_LIMIT_REASON`.
4. **Соперник видит то же физически** (кубы приходят на его стол, если Парламент открыт; иначе — лента), **принятые сцены не
   ломаются** (TR03 / TR04 / TR12 / заседание — побайтно; A/B).
5. **Полировка** — по чеклисту §7 с названным минимумом сверх P0 (§6).

### Правила чтения (каждое — закрепить спеком карты)
1. **Требование** — Красные (у власти или 2 ваших делегата на их резолюции); условие розыгрыша. Выданный картой эффект (Council
   Seat TR36) дорогой не считается.
2. **Получатели голосов — резолюции Красных и «Марс вперёд», стоящие НА ГОЛОСОВАНИИ** (`slotOf(party)`): по одной на партию или
   ни одной. Принятая карта, сброс, колода — нет. Если Красные правят принятой картой, их резолюции на голосовании нет — и это
   не пропуск, а названный ноль («резолюции Красных нет на голосовании»).
3. **По 1 нейтралу на каждую такую резолюцию** — голос нейтрального игрока: лидера карты не меняет (пока там есть куб игрока),
   ПОБЕДИТЕЛЯ ГОЛОСОВАНИЯ — может (больше голосов; ничья — слот ближе к правительству). Чей-то доступ к партии не меняется.
4. **По 1 нейтралу в области Народной поддержки Красных и «Марс вперёд»** — всегда, есть резолюция или нет; область ≤ 3 —
   излишек не кладётся (названный ноль «область заполнена», как у Солнечной фазы).
5. **Порядок — печатный, запас судится по ходу:** резолюция Красных → резолюция «Марс вперёд» → область Красных → область «Марс
   вперёд»; пустой запас режет оставшихся («нейтральных не осталось»). Запас — производная: 14 − голоса − поддержка.
6. **Затем +M€ = нейтралов В ИГРЕ ПОСЛЕ размещения** — голоса на всех трёх слотах (любых партий) + все шесть областей =
   `14 − neutralSupply()`; максимум 14. Обычный `stock.add(MEGACREDITS, n, {log, from: {card}})`.
7. **Всё — в одном ответе, без вопроса.** Ничего не паркуется; «Разыграть карту» — один POST.
8. **Делегаты карты — нейтральные:** не считаются в задание председателя «отправить N делегатов», не дают доступа к партии, не
   двигают Карьеру; MarsBot карту не играет, его кубы — не нейтральные (в счёт не входят).
9. **Журнал** — корень розыгрыша: строка на каждый нейтральный голос (резолюция), строки поддержки (существующие ключи фазы с
   партией-подлежащим), строка M€ С ОСНОВАНИЕМ («нейтральных делегатов в игре: 14»). Нотификация соперника — то же.
10. **Save / load** — всё в реестре Парламента; запись исхода (A3) не сериализуется (презентационное кольцо, закон TR24).
