### Карта

**A1 · `AndOptions` НЕ ИМЕЕТ консольной поверхности — закон P49 нарушен формой.** Живой `and` → `composite`, «nothing native serves them»; `andOptionParts` режет лишь `or | card | player`, `resource` → `'other'`; дверей для `resource` в `openChoice` нет; карта сброса внутри `optionInput` не вооружается (`preselectedDiscardsOf` — только верхний уровень). P49 выбрала ПОСЛЕДОВАТЕЛЬНОСТЬ адресуемых промптов именно потому, что консоль не отвечает `and`. Заметка чек-листа «legacy `AndOptions.vue`» — мёртвая.

**A2 · Ни один «?» не адресуем.** Оба `SelectResource` без `markChoiceContext`/`withGainAmount`; корень без маркера → адрес позиционный («анонимный»); спенд-«?» и гейн-«?» неразличимы для `extractPlayRewards` — чип «?» прилипнет к ПЕРВОМУ незанятому `resource`-шагу (трате), и полетит не тот ресурс.

**A3 · Режима ТРАТЫ у общего шага «?» НЕТ.** Дорожки всегда шесть, всегда «получение» (`stock + gain`), любая принимается; сервер просто не включает нулевые ресурсы в `include`. Владелец: «только 1 ресурс — без LB/RB, просто селект кликом» = радио-дорожки, A выбирает; нулевые — ПОКАЗАНЫ и погашены с причиной (инвариант 2), не спрятаны.

**A4 · «?» РОЗЫГРЫША спрашивается ЖИВЫМ после нажатия.** Очередь старта и «ВЫБОР ПРОЛОГА» пре-собирают только `or` («ВАРИАНТ» P44); `resource`-шаг розыгрыша приходит палитрой `ConsoleTaskHost` внутри старта; волна героя ресурс не несёт (ответа нет).
