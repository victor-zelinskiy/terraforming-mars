## Диагноз (подтверждён файл:строка на `16fde5dc4c`; перепроверить A1–A8 на своём HEAD и кадрами «ДО»)

**A1 · Четыре безымянных OR подряд.** Сервер спрашивает `OrOptions` без `choiceContext` и без метаданных опций → роутер даёт `choice/generic` → в старте (сцена уступила полю после первого размещения или ещё не уступала) и в середине партии вопрос встаёт **отдельной модалкой семьи `ConsoleTaskHost`** с английскими титулами («Place a city», «Discard 3 cards» — RU нет), крошка старта и карта-герой НЕ продолжаются: «модалка, которая пришла» (CLAUDE.md § ОДИН ПОТОК, п. 1–2). Вид тайла в такой модалке читался бы ТОЛЬКО из титула (инвариант 1).

**A2 · Выбор без последствий.** «Discard 3 cards» предлагается на каждом шаге наравне с размещениями, хотя момент сброса НИЧЕГО не меняет (рука не участвует в размещениях) — четвёртый вопрос без исхода, доктрина тщетных действий (`futile-actions.md`).

**A3 · Пропуск океана нем.** При максимуме океанов шаг считается сделанным без факта, без журнала, без чипа превью; единственный след — `maxoceans` на `canPlay` (инвариант 4). В старте недостижимо, в середине партии (WG Project / P45 / Double Down) — реально.

**A4 · Размещения без источника и плана.** Ни одно `Place*Tile` не получает `sourceCard` / `placementContext` / `followUpPlacements` → досье поля не называет карту, не говорит «затем ещё 2», а баннер размещения ведёт себя по умолчанию клиента (`PlayerInputModel.ts:215` «previous client-hardcoded behaviour»); `PlaceCityTile` / `PlaceGreeneryTile` опции `followUpPlacements` не знают вовсе.
