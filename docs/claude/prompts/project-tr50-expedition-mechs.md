## 7. Режим работы
**Коммиты карты**: (1) карта + спек + локаль + лор (+ арт, когда будет); (2) e2e — три фикстуры + спек; (3) документы — журнал § TR50,
`docs/TURMOIL_REDUX_EVA_MECHS.md` §2 (седьмой держатель, таблица смыслов мехов), чеклист §4, реестр раздел AB, промт. **Коммиты полировки** — отдельно
(`Polish (TR50 route): PL-### — …`), с «до / после» и гардом. Перед каждым: `npm run lint`, `npm run build:test`, `npm run make:cards`, `npm run
make:json`; перед визуальной проверкой — `npm run make:css` + `npm run build:server`. **Не пушить.** Батч — после карты и кадров 4K спутника / шага цели /
панели оплаты, ДО полировки.
Гочи: `turmoilReduxExpansion: true` + `coloniesExtension: true` в `testGame`; декларативный `or` откладывает `OrOptions` — `runAllActions` перед
`popWaitingFor`; старый бандл новую карту не рисует — стенд на своей сборке; на 4K ждать `.con-hand:not(.con-hand--transit)` до `focusCard`; имена
кадров скринкаста = время получения; 4K-раскадровка руки идёт в ≈ 0,3×; e2e-сэмплер — `setInterval`, не rAF; `--grep "tr50 "` Playwright
регистронезависим и ловит describe «TR50 stand»; сетка «Действий карт» 2D — плитка с «ИЛИ» одна на вариант, не на карту; патчи с regex / обратными
слэшами — только файлом через `<<'EOF'`; LESS `&--mod &__elem` внутри блока профиля = мёртвое правило (гард `lessDeadSelectorGuard`); `python3` —
заглушка Store; `eqeqeq` без исключения для null; `rtk grep` с фиксированной строкой виснет — Grep-инструмент; `npm run build:server`, не голый `tsc`;
`build:client` может молча «compiled with 1 error» — mtime `main.js`; новая карта перетасовывает сидированные Redux-фикстуры — добавлять только свои
JSON; юниты — на тихой машине.
**В отчёте:** что встало само (роль, плитки, причины, полёты) — по пунктам §2 (а)–(д); вердикты по моментам (§5) с кадрами 4K — отдельно «куда
положить мех — понятно?» и «чем платится TR50 — понятно?»; батч и ответы; регрессия; новые ключи; подтверждение решений 1–7; арт. **Раздел
«ПОЛИРОВКА»** — с СОБСТВЕННЫМИ находками. **Явно — всё, что не получилось, и почему.**
