## Диагноз (подтверждён файл:строка на `f82e3298fb`; перепроверить A1–A6 на своём HEAD и кадрами «ДО»)

**A2 · Реакция без записи.** `player.defer(() => stock.add(…))` без `from` исполняется вне скоупа `withEffect(…, 'card-played')` → `recordReaction` не видит воздействия → сцена срабатывания (подъём карты, жетон с её строки эффекта), лента и строка журнала «сработал эффект» — слепы; рельс просто тикает (A3 — «правда без истории»). **A3 · Три награды одного ответа на старте.** +3 (герой), +1 (реакция), 2 карты (батч) — порядок и такты не доказаны для пролога-реактора, отвечающего В РЕЛЬС (TRP9 отвечал на карту); риск второго экземпляра реактора на сцене (PL-1117), риск «3 → 4» одним прыжком, риск, что реакция играется сценой сборки добора ПОВЕРХ волны героя.

**A5 · Ветка «метка не с карты».** `onNonCardTagAdded(PLANT)` в премиум-скоупе недостижима (только Underworld) — оставить, не чинить, спек назвать.
