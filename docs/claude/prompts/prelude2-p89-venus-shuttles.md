(б) С ПАРЛАМЕНТОМ (мягкие ворота К4): ответ паса несёт производство, ВСЁ заседание и игру УЖЕ в DRAFTING/RESEARCH поколения N+1; `detectGenerationScene` → `flipTo undefined` (`presentedGeneration` держит поколение заседания — Р7); доход играет, сцена ПОДНИМАЕТ ЗАСЕДАНИЕ (`rose = 'parliament'`); `observeDraftWorkspace` выходит рано (`betweenGenResearchLive` ложна при `parliament.phase`), а спад `draftFrameLive` ещё и `resetDraftWorkspace()` — защёлки в false; заседание идёт (verdict → … → results); A «К драфту» → `closeInto` → ответ закрытия: `parliament.phase` → undefined, `waitingFor` — пик драфта; `observeDraftWorkspace` теперь работает, **но `prev.game.phase` УЖЕ DRAFTING (`wasDrafting` true) — ни одна защёлка не взводится**; спад `parliamentSittingFrameLive` → `handSittingToDraft` → `swap()` → `enterWorkspace('draft')` → `created()`: `packetKey === hydratedPacketKey && !sawDraftStart` → **`deal.dispose(); shouldRunDealOnce(dealKey); return`** — карты показаны мгновенно, память раздачи СЪЕДЕНА (повторно не сыграть). Без драфта — то же: `stage === 'buy'` с ложной `sawResearchStart` → ветка «Reload straight into the buy» → `finishRiseScene()` мгновенно. Сцены поколения при закрытии НЕТ: «ПКЛ.» меняется реактивно (`shownGeneration`), без бита `runGenerationFlip`; комментарий `handSittingToDraft` «the counter's flip» обещает ожидание, которого директор не знает. Юнит `consoleDraftFlow.spec:282–309` знает только «смена фазы» и «гидратация» — «место допущено к поколению, когда фаза уже шла» не покрыт; e2e `console-parliament-softgates` проверяет бесшовность и счётчик, но НЕ раздачу; Redux-фикстуры с драфтом нет вовсе.

**П2 · Что должно быть (владелец: «доработать и отполировать»).** Та же премиум-фраза, что у стола без Парламента, только её первая половина (доход) уже сыграна при подъёме заседания: ИТОГИ (замороженная поза) → A «К драфту» → ответ → [долг поля — поле первым, как сейчас] → **ФЛИП «ПКЛ.» N → N+1 на полосе** (бит сцены поколения, который для места с заседанием был отложен — Р7 «флип при ответе»: сейчас реактивный скачок) → Парламент растворяется, драфт входит ОДНИМ flush (как сейчас) → **ПЕРВЫЙ ПАКЕТ СХОДИТ С РЕАЛЬНОЙ HUD-КОЛОДЫ** карта за картой в подготовленные слоты (`launchPacketDeal`, первый пакет) → пик. Без драфта: покупка исследования — четыре карты сходят с колоды слоя (`prepareBuyArrival` / `launchBuyDeal`). Перезагрузка ПОСЛЕ закрытия — по-прежнему мгновенно (PL-924 — инвариант); сворачивание/восстановление — без повтора (память раздачи). Ни кадра поля между Парламентом и драфтом (контракт `softgates`), плиты нет.

Долг поля (бот сажает океан) — как сейчас: поле → история → флип → драфт (флип — после истории поля, перед входом; порядок зафиксировать стендом E).
