### Правила чтения (каждое — закрепить спеком)
1. Цена действия — 1 энергия (`spend.energy`); при 0 энергии действие недоступно с авто-причиной «Not enough energy» —
   без бесподобного `canAct` (иначе красный `cardReasonConsistency`).
2. ПО = число мехов на карте (0 → 0, 3 → 3), общий путь `resourcesHere`.
3. Требование — только через DSL: дикая метка Учёных и бонус R&D Funding засчитываются сами. Метка Марса наукой не
   считается.
4. **Мехи на этой карте — не деньги.** Платёжная единица `mechs` читает только EVA Mechs. С обеими картами в табло оплата
   карты с меткой Космоса предлагает мехи EVA и не трогает мехи TR11.
5. **Мех — полноценный ресурс карт**: Веста и любой эффект «мех на любую карту» могут положить мех сюда; он считается ПО.
   Снятие ресурсов атакой — обычный путь, без исключений.
6. Действие Беспилотных конвоев (TR66) тратит мех СО СВОЕЙ карты — мехи TR11 ему недоступны.
7. MarsBot карту не играет.

держатель мехов, два одинаковых действия в табло), результаты трёх проверок, решения (имя), гэпы. Гочи: `python3` —
