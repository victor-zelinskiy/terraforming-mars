## 2. ЧТЕНИЕ ПРАВИЛА (каждый пункт — спеком `tests/parliament/MarsFirstBudget.spec.ts`)

1. **Печатный порядок = исполняемый, для каждого места по очереди:** плата 12 → выплата → город. Место 1 закончило все
   три — только тогда место 2 (так ходит драйвер, `ParliamentPhase.ts:586–600`). Не переставлять ради того, чтобы место
   смогло заплатить.
2. **Плата — семейная целиком:** частичная при нехватке (5 M€ → платит 5 из 12, запись «было должно»), 0 M€ — названный
   пропуск; дальнейшие части идут всё равно. **Бот не платит** (D3: поборы закона боту не применяются).
3. **Счёт — две метки сложением:** стройка + Марс, режим семейства (`RESOLUTION_TAG_COUNTING_MODE = 'raw'`): печатные
   метки всех источников в игре; карта с обеими — найти в скоупе реальную и закрепить ею — = 2; дикая метка не считается;
   метки разыгранного события лицом вниз не считаются; разбивка по меткам в записи (`countedByTag`). Ноль — назван, только
   когда и метки, и влияние нулевые. **Бот не получает** (D3: выплата «за метки» потребовала бы перевода позиций треков).
4. **«Каждый игрок размещает тайл города»** — каждый УЧАСТНИК, **включая бота** (уточнение D3, §4.2), голосовал он или нет;
   нейтральный победитель ничего не отменяет. Город — по ОБЫЧНЫМ правилам города (`'city'`: клетка Марса, не рядом с
   другим городом; резервные клетки — только своими картами, не здесь). Человеку выбор клетки показывается всегда
   (инвариант 3); бот выбирает своим правилом (`AutomaTilePlacer.placeCity`). **Обязателен** (Р2): печать говорит
   «places», не «may place».
5. **Нет законной клетки → названный пропуск** («No space left for a city tile» — ключ уже есть, `CityStandardProject.ts:53`)
   с записью `skipped`; ничего взамен. У бота — тот же пропуск, **без Failed Action** (`onEmpty: 'impossible'`: закон — не
   печатная иконка карты бота).
6. **«По часовой от первого игрока»** = порядок поколения (`playersInGenerationOrder`) от первого игрока ТЕКУЩЕГО
   поколения (заседание идёт до передачи маркера); **бот стоит в этой очереди на своём месте**: бот — первый игрок →
   бот ставит первым. Порядок ВАЖЕН: город раннего места закрывает соседние клетки для следующих — спек с двумя местами,
   чьи лучшие клетки соседствуют, и спек «бот первый закрывает клетку человека».
7. **Клетка платит, как платит любой город в фазе Парламента** (`Phase.PARLIAMENT` — тайлы с бонусами): печатный бонус
   клетки, соседство с океаном (+2 M€ за океан), стоимость Ares, если Ares. **Правящая партия на этот момент — «Марс
   вперёд»**: её эффект «тайл на Марсе → 1 сталь; город → ещё карта» срабатывает у КАЖДОГО ЧЕЛОВЕКА; **у бота — нет**
   (официальное «MarsBot ignores the ruling party's policy» — аспект `party-effects` у бота выключен, это не меняется).
   Реакции стола (Tharsis Republic, Immigrant City, Pets, Rover Construction, Capital…) — движковые, на город бота тоже
   (Tharsis Republic человека платит за ЛЮБОЙ город — спек).
8. **Деньги на стоимость клетки — после выплаты:** клетки с ценой размещения фильтрует движок по средствам ПОСЛЕ платы и
   выплаты (`board.canAfford`); спек: место с 0 M€ после платы не видит платных клеток, видит бесплатные. Бот — по своим

9. **Задание:** розыгрыши с меткой Марса в своё действие; город заседания в задания не идёт (корень `political-phase` —

10. **Однажды за принятие:** ключи идемпотентности драйвера; перезагрузка внутри выбора клетки перестраивает тот же

### 4.1 Карта — две строки счёта, один вариант объявления

```ts
levy: {resource: MEGACREDITS, amount: 12, recipient: 'each'},
scaled: [{id: 'megacredits', unit: {kind: 'stock', resource: MEGACREDITS}, perInfluence: 1, count: {id: 'buildingMarsTags', per: 1}, recipient: 'each'}],
tileGrant: {tile: 'city', placement: 'any-legal', recipients: {kind: 'everyone'}},
immediateSteps: [levyStep(ID, LEVY), MEGACREDITS_STEP, tileGrantStep(ID, GRANT)],     // печатный порядок
```

- **Счёт `buildingMarsTags`** — три аддитивные строки по образцу `plantMicrobeAnimalTags` (список id, `resolutionCountKind`
  → `{kind: 'tags', tags: [Tag.BUILDING, Tag.MARS]}`, ветка предиката); никаких отдельных id на каждую метку. Проверить, что
  `Tags.count(Tag.MARS, 'raw')` видит метку без гейта Pathfinders (`Tags.ts:144, 171`); если гейт есть — сказать в отчёте и
  решить общим способом, не веткой для карты.
- **`tileGrant` — ВТОРОЙ ВАРИАНТ объявления.** Сегодня в нём смешаны два вопроса — «кому» и «куда». Развести:
  - `placement: 'own-city' | 'any-legal'` — КУДА (ярус на свой город по `city-tier` | клетка по обычным правилам
    `'city'`); `tileGrantStepKey` / `tileGrantCountId` / ключ «куда» в `tileGrantModel` — исчерпывающие `switch`;
    `tileGrantCountId` для `any-legal` — `undefined` (законных клеток почти всегда много, число ничего не объясняет; «0
    клеток» — честный пропуск на исполнении) — читатели учатся `undefined` (`ResolutionCounts.ts:244`).
  - `recipients: {kind: 'threshold', winner: true, influenceAtLeast} | {kind: 'everyone'}` — КОМУ (RX20 мигрирует на
    `threshold` без смены поведения для людей; `tileGrantEligibility` получает исход `'everyone'`).
  - Экспорт в манифест (`export_card_rendering.ts:228`) копирует новое поле; объявление не сериализуется — проверить
    только, что запись `city` старых сохранений Skyscrapers читается.

- **Модель места** (`ParliamentModel.ts:210–230`): рядом с `enactment` — `tileGrant: boolean` (аспект), чтобы клиент
