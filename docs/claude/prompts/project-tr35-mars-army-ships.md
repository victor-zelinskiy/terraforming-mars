## 7. Режим работы
**Коммиты карты**: (1) карта + спек + локаль + лор + арт (если есть); (2) документы (журнал § TR35, документ переписи §4 — строка

— …`), PL-097 — со своим Deck-пресетом и гардом; словарь — после батча. Перед каждым: `npm run lint`, `npm run build:test`,
`npm run make:cards`, `npm run make:json`; перед визуальной проверкой — `npm run make:css` + `npm run build:server`. **Не
пушить.** Батч владельцу — одним `AskUserQuestion` после P0 и до остальной полировки.
Гочи: `coloniesExtension: true` в `testGame`; старый бандл новую карту не рисует — стенд на своей сборке; имена кадров
скринкаста = время получения (DOM-пробник 10 мс для порядка); `--grep "tr35 "` ловит describe; сетка «Действий карт» 2D; `python3`
— заглушка Store; `eqeqeq` без исключения для null; bash heredoc с длинным RU-текстом ломается — Write; нумерация реестра общая.
**В отчёте:** что встало само (всё действие — модуль), вердикты по моментам подачи (§2) с кадрами, батч владельцу и ответы, PL-097
до / после, регрессия, гарды, новые ключи, подтверждение решений 1–6, арт. **Раздел «ПОЛИРОВКА»** — с перечнем СОБСТВЕННЫХ находок
