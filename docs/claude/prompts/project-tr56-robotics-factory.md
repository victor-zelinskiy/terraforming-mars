- Детектировать ветку / шаг по заголовку (только маркеры и превью сервера); искать держателей на клиенте; авто-выбор единственного держателя или единственной ветки цели.
- Скрывать ветку без держателя; красить её янтарным вместо причины; второй язык «выбери карту» рядом с `ConsolePlayedTargetStep` (ни своя сетка в композере, ни своя полоса в плитке).
- `v-if`-переключение строки цели при смене варианта (мигание); перецентровка колонки; `filter` на любом состоянии; ширины в `vw` / px без `conUiScale`; `title`-атрибут; литерал кнопки.
- Жетон из ничего: нет видимой печатной иконки ветки → честная деградация, названная в трейле.
- Ломать селекторы стендов без перевода в том же диффе; полный regen фикстур; `git stash`; bare `git push`; переписывать RU чужих ключей (новый ключ — новое английское имя).
- Трогать файлы прогона TR54 до его коммита.
