**Что это за карта.** Синяя (ACTIVE), 7, метки **Наука + Растение**, требование **Зелёных** — ПЕРВАЯ плашка Зелёных в наборе (Redux-требования
до сих пор: Марс прежде всего, Союз, Красные). Держатель **data**: розыгрыш +2 data; эффект «после того как вы разыграли метку микроба или
животного — +1 data сюда»; действие «2 data отсюда → +1 пр. растений». Всё — классы, которые уже стоят: триггер = TR05 / Decomposers, действие =
Deuterium Export, ответ Зелёных на рост пр. растений = `PartyEffects` + прогноз. Поэтому карта — ≈ 35 %: декларация + один триггер с близнецом.
Её ценность для задачи — **маршрут**, который она проходит и на котором видны швы: (а) **розыгрыш микроба / животного ИЗ РУКИ при TR38 в табло** —
сегодня +1 data на держатель вообще НЕ ЛЕТИТ (§ II.A К-S1); (б) **действие с производством под Зелёными** — жетон пр. растений на рельс и
+1 пр. M€ Зелёных тактом после (механизм есть, ни одного e2e на ПРОИЗВОДСТВО-ответ после действия); (в) держатель data в чужих шагах (Учёные,
TR01, Плутон Redux). Часть II — большая итерация полировки, которую владелец заказал вместе с картой.

**Оценивается — в этом порядке веса.**
1. **Карта — декларация** (`ActionCard` + `behavior` + один триггер с близнецом прогноза), гарды §3 — ворклист пуст; правила 1–12 закреплены спеком.
2. **Ответ стола на розыгрыш ЛЕТИТ** (К-S1 — якорь части II, класс): микроб из руки → в сцене «Разыграно» держатель выходит из своей полосы,
   «+1 [data]» летит с метки разыгранной карты в капсулу держателя, счётчик тикает на касании, держатель садится обратно — ни одного числа без
   причины; и родственное PL-035 (ответ стола на розыгрыш без РТ сливается с ценой).
3. **Бесшовность главных flow на 4K** (часть II): PL-120 (пустая зона руки ≈ 1 с между посадкой и хостимым шагом), PL-112 (анонс «эффект
   партии получен / потерян» — принято владельцем «следующей картой» = эта), открытые швы реестра и аудита § II.B — каждый в общем механизме,
   с законом и гардом.
4. **Подача действия TR38 на 4K**: −2 data с капсулы → импульс → жетон пр. растений с печатного `.pcard-prod` на рельс → +1 пр. M€ Зелёных ПОСЛЕ
   касания (никогда с ценой, никогда раньше).

2. **Розыгрыш**: +2 data на ЭТУ карту (`behavior: {addResources: 2}` — фиксированная цель, исключение из «нет автовыбора»), больше ничего.
3. **Триггер — по МЕТКЕ**: каждая метка микроба или животного на карте, которую разыграл ВЛАДЕЛЕЦ, → +1 data; карта «микроб + животное» → +2;

4. **Метки не с карты** микроба / животного в движке не бывает → `onNonCardTagAdded` не объявляется (шапка называет; новый источник — спек упадёт

## II.C ПРОХОД БЕСШОВНОСТИ — метод (он же приёмка части II)
Каждый flow снимается ЦЕЛИКОМ раскадровкой CDP 4K (`TM_E2E_STORYBOARD=1`; кадры именуются временем ПОЛУЧЕНИЯ — порядок сверять по видимому
событию / DOM-пробнику 10 мс), от нажатия до поля, и читается по восьми вопросам шва: **(1) Встроено?** Этап, который открыл игрок, стоит в зоне хоста
(та же инстанция, Teleport), а не отдельной полосой поверх. **(2) Крошка растёт?** Корень и субъект — те же узлы весь flow, анимируется только хвост,
встроенная поверхность не титулует себя. **(3) Фраза, не склейка?** COMMIT → RELEASE на месте → UNFOLD из rect ушедшего → REVEAL; нет `v-if`-моргания,
нет кадра без объекта, нет пустой зоны > ~400 мс. **(4) B = уровень назад?** Глагол и подпись — от одной функции фазы; «свернуть» сохраняет выбор,
курсор, раскрытую карту. **(5) Конец — одна концовка?** Закончивший flow уходит на поле, а не в обзор с серой «Активирована». **(6) Результат переживает
поверхность?** Награда отделяется в слой приложения и летит в ИЗМЕРЕННОЕ место. **(7) Причина видна?** Каждое число, которое поменялось, имеет полёт или
строку причины на том же экране. **(8) Бар честен?** Ни одного глагола, который ничто не принимает (в том числе во время фейда).
**Flow для прохода (минимум):** розыгрыш из руки — AUTOMATED / ACTIVE / EVENT, с хостимым шагом (TR03 голос, TR04 / TR37 ходьба, TR31 нейтралы, TR07
колония) и без; «Действия карт» — без выбора (TR38), с вариантами (TR34), с добором (TR05), с покупкой (Inventors' Guild), с целью (TR29); стандартные

## Режим работы
**Коммиты карты**: (1) карта + спек + локаль + лор + арт (если есть); (2) e2e — фикстура + спек (проверка (A) — после К-S1, A/B); (3) документы —

iteration): PL-### — …`), каждая с «до / после» (кадры 4K или замер) из СВОИХ снапшотов и гардом; класс в общем пути — регрессия соседей обязательна.
Перед каждым: `npm run lint`, `npm run build:test`, `npm run make:cards`, `npm run make:json`; перед визуальной проверкой — `npm run make:css` +
`npm run build:server`. **Не пушить.** Батч владельцу — после прохода бесшовности, до реализации композиционных правок.
Гочи: `coloniesExtension: true` в `testGame`; старый бандл новую карту не рисует — стенд на своей сборке; рост колоды сдвигает сдачу — свободные столы
фикстур прибивать корпорациями без первого действия (память TR37); имена кадров скринкаста = время получения; e2e и тяжёлые процессы не совмещать (A/B
таймингов — только на тихой машине); `position: fixed` — всегда контекст наложения (PL-101); `clearPanelRewardHold()` сносит чужие холды — сцена
отпускает только свои; `python3` — заглушка Store; `eqeqeq` без исключения для null; bash heredoc с длинным RU — Write; `node -e` с бэктиками — Edit;

по таймауту (память `logged-error-stack-times-out-full-client-suite`).
