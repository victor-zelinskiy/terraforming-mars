**Оценивается — в этом порядке веса.**
1. **РТ ОТ ДЕЙСТВИЯ КАРТЫ — НАГРАДА, А НЕ ЧИСЛО, КОТОРОЕ ИЗМЕНИЛОСЬ** — для КЛАССА действий (TR28, UNMI, Caretaker Contract,
   Equatorial Magnetizer, вторая ветка Nitrite Reducing Bacteria и Titan Air-Scrapping): жетон из печатного значка РТ на
   строку рейтинга, тик на касании, ответ стола — следом. У действий, где РТ приносит ТАЙЛ или шкала, — ничего не меняется.
2. **ОДНА КАРТА — ДВА ТАКТА, И ПЕЧАТНЫЙ РЯД — ЭТО ТАЙМЛАЙН.** `→ [истребитель], −2 [истребитель] : [РТ]`: истребитель садится
   на карту (капсула c → c + 1), два истребителя УХОДЯТ с карты в значок РТ (c + 1 → c − 1), жетон РТ летит на рельс. Игрок
   видит «+1, затем −2», а не «−1». Промежуточные значения честные: на лице ни разу не стоит c − 2 или «−1».
3. **СЕРВЕР: ОДНО ЧТЕНИЕ СОСТОЯНИЯ.** Превью и исполнение читают счётчик одной функцией: при 0 истребителях действие обещает
   и даёт только «+1», при ≥ 1 — «+1, −2, +1 РТ». Чипы композера никогда не обещают РТ, которого этот ход не даст.
4. **Принятые сцены не ломаются:** тайминг тика РТ у UNMI / Caretaker / Equatorial меняется — это цель, и она снята A/B;
   всё остальное на их маршруте (плата, фиксация карты, уход workspace) — побайтно прежнее.
5. **Полировка** — по чеклисту §7 с названным минимумом сверх P0 (§6).

### Правила чтения (каждое — закрепить спеком карты)
1. **Требование** — Союз; условие розыгрыша. Действие работает и без Союза.
2. **Розыгрыш ничего не делает**, кроме выкладки карты (держатель истребителей с нулём).
3. **Действие — одна последовательность без выбора:** +1 истребитель сюда; затем, если здесь ≥ 2, ровно 2 сбрасываются и
   +1 РТ. Сброс ОБЯЗАТЕЛЕН (не «можете»). С 0 истребителей — только +1; с 1 → 2 → 0 и РТ; с 3 → 4 → 2 и РТ (сбрасываются
   ровно два, один раз).
4. **Действие доступно всегда** (положить истребитель можно всегда); раз в поколение, как у любой синей карты.
5. **РТ — обычный `increaseTerraformRating(1)` под источником карты** в фазе действий: задание председателя считает,
   правящие Зелёные платят +2 M€, `hasIncreasedTerraformRatingThisGeneration` открывает действие UNMI, атрибуция в разборе
   счёта — карте, хуки `onIncreaseTerraformRatingByAnyPlayer`. Налога Красных в Redux нет (класс TR26).
6. **Истребители сюда кладут и другие** (Redux-Веста — «на ЛЮБУЮ карту»): они считаются при пороге «≥ 2» — и в вехе
   «4 истребителя или меха» (таблица).
7. **Истребители здесь ничего не стоят** (ПО нет) и ни во что не тратятся, кроме собственного действия.
8. **Порядок событий = порядок значков**: добавлен → сняты два → РТ. Три события под источником карты, ни одного дважды.
9. **Save / load**: счётчик переживает сохранение; действие после загрузки читает его.
10. **MarsBot** карту не играет.
11. **Журнал**: «${0} added 1 fighter to ${1}» (существующий ключ), снятие двух с причиной (взять существующий ключ формы
    «removed … from … to …» или завести один новый), «gained 1 TR».

- **Категория коммита:** `global` остаётся для шкал; для прямого РТ импульс садится на значок РТ и ХЭНДОФФ зовёт полёт
  рельса (не «HUD carries the change»). Назвать это в `ActionCommitKind` честно (новый вид или подвид `global`) — без
  литерала по имени карты.
- **Деградация названа**, холды ограничены, reduced motion ничего не сеет.
- **Соседи — A/B:** UNMI (`unmi-liner`), Caretaker Contract и Equatorial Magnetizer (`arrange` на любой фикстуре с их
  картами в табло; если недостижимо без генератора — сказать): «до / после» кадры и отметки времени; меняется ТОЛЬКО момент
  тика рейтинга (и ПО) и появление жетона. Nitrite / Titan Air-Scrapping — вторая ветка: жетон РТ летит, капсула падает
  как раньше (решение 6).

### B2 · ДВА ТАКТА НА ОДНОЙ КАРТЕ — печатный ряд как таймлайн
- План коммита TR28 при ≥ 1: цепочка из трёх звеньев, каждое стартует по касанию / отлёту предыдущего:
  ① `card-resource +1` (значок истребителя → капсула героя; капсула c → c + 1 на касании);
  ② `card-resource −2` с карты (капсула → значок РТ печатного ряда; капсула c + 1 → c − 1 НА ОТЛЁТЕ — закон левии:
  «the counter ticks on DEPARTURE», `direction: 'loss'` в общем директоре);
  ③ `stock:rating +1` (значок РТ → рельс — B1).
  Импульс сначала садится на ПЕРВЫЙ значок результата; кольцо на значке РТ срабатывает, когда рождается жетон ③.
- **Арифметика удержания:** капсула лица = значение модели (c − 1) + ещё не отлетевшие (2) − ещё не севшие (1) = c. В
  любом кадре от применения вида до конца фразы капсула показывает c, c + 1 или c − 1 — никогда c − 2, никогда отрицательное.
  Спутник ДОП. РЕСУРСЫ (если он показывает истребители) и всё производное — по той же арифметике.
- **При 0:** только ①; капсула 0 → 1; никакого РТ и никакого ответа стола.
- **Workspace стоит** (статус «Выполняется…»), пока карта — цель ① или источник ②; складывается под летящий жетон ③
  (решение 4). Страховка коммита 1.4 с не режет фразу: фраза держит свой холд с собственным потолком и именем.
- Прерывания: отказ сервера → откат (капсула и рейтинг как были, ничего не летало); «свернуть» / перезагрузка посреди —
  холды отпущены, числа честные.

### B3 · До нажатия композер говорит ВСЁ
При 0: «[истребитель] 0 → 1». При ≥ 1: «[истребитель] c → c − 1» с формулой «+1, −2» (не голое «−1» — чип должен уметь
сказать, что произошло два движения, или рядом два чипа), «РТ n → n + 1», «⚡ сработает +2 M€» при правящих Зелёных.
Доступность — всегда; платы — нет. Плитка в «Действиях карт»: мета-строка не обещает РТ при 0.

### B4 · Лицо, капсула, зритель
Капсула истребителей на лице (как у TR08); у соперника — счётчик на карте в «Разыграно» / «Информации» (публичный, как у
любой капсулы) и РТ на его строке; журнал — три строки под одним корнем; нотификация.
