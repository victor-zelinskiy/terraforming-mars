**АКЦЕНТА ВЛАДЕЛЬЦА НЕТ** — карта сама по себе — декларация в несколько строк (`stock: {energy: 9}`, `victoryPoints: 2`, плашка Индустриалов, метка Энергии), поэтому
по правилу «Премиум-планка» бюджет полировки — всё сверх карты, и фокус выбран по МАРШРУТУ карты: её печатные **«2 ПО»**. Подготовка показала, что ячейка ПО
рельса — единственный счётчик консоли, который живёт мимо закона причинности почти целиком: держится только для ПО, выведенных из РТ, и ПО, которые приносит
ресурс карты; всё остальное (печатные ПО розыгрыша, тайлы — свои и ЧУЖИЕ, +5 вехи, перераспределение наград, потери от атак) тикает в кадре применения вида
— часто раньше, чем причина видна. Ячейка ПО видна по умолчанию (приватный счёт выключен — `privateScoreState.ts:34`). Цель итерации: **«каждое очко
приходит из своей причины»** — один вид жетона «ПО», одна сверка с разбором счёта сервера, одна точка приземления, в каждом источнике. Вторые кандидаты
маршрута (прогноз квеста председателя для метки Энергии, первая плашка Индустриалов) — в §6. Финал — кадрами 4K в батче владельцу.
