## Диагноз (подтверждён файл:строка на `a4d0777405`; перепроверить на своём HEAD)

### Карта

**A1 · Церемония старта ПРИКОЛОТА К ПЕРВОЙ ВЕТКЕ и ничего не пре-собирает.** `prefetchPlayRewards` читает `preview.branches[0]` и `forecastForFixedBranch(…, 0)`; `stepResponses: {}`. Для P44 ветка 0 — температура: награда рельса, жетон РТ и «Сработает» опишут температуру, какую бы ветку игрок ни выбрал; сам OR спрашивается ЖИВЬЁМ после нажатия — решением эффекта в `.con-start__embed` (три ГОЛЫХ титула: метаданных у опций OR-поведения нет, `consoleOrChoice` чипов не построит; максимум шкалы — молчит: `warnings` опций в действия решения не копируются; ветка, отвергнутая `canExecute` (Красные на классике) — молча ВЫПАДАЕТ, в `disabledOptions` не попадает). Закон «EVERY CHOICE IS MADE BEFORE THE COMMIT» и инварианты 2/3 нарушены на самой первой карте-выборе старта. Ни один пролог/стартовая карта скоупа с OR при розыгрыше не существовал (Атмоскуп — bespoke с метаданными, через руку).

**A2 · Печатные строки не режутся по косой черте.** Скан печатает ТРИ строки через `/`; `printedVariantRows` режет только по символам OR → даже в композере руки три ветки упадут в «слова + чипы» (TR51 — «опция ЕСТЬ печатная строка»).

**A3 · Добор «со значком аэростата» — НЕПРОЗРАЧНЫЙ `include`: лента есть, правила нет.** `searchOf` → `undefined`: батч без `search`, факт поиска без `rule`, шапка забора «ПОЛУЧЕНО 2» без бейджа поиска, отброшенные — без причины, плитка правила в журнале не рисуется; превью добор НЕ обещает (чипа нет → `drawExpected 0` → место источника не монтируется, карты «прилетают из ниоткуда»); `cardPlayPreviewCoverage` / `cardPlayReplayCoverage` ходят только `projectCards` — прологи они НЕ проверяют, bespoke-добор без хука проходит молча. Celestic — тот же `include`, та же немота. `Behavior.DrawCard` не умеет `include`, а `resource: FLOATER` — уже правило («карты, ХРАНЯЩИЕ аэростаты» ≠ «со значком»: `floaterCards` — ручной список печатающих значок).

**A4 · Правила посреди/на старте — что честно.** Максимум шкалы — ветка предлагается с предупреждением (апстрим); на старте налога Красных нет (`phase !== ACTION`), под Redux его нет вовсе → под Redux карта никогда не сгорает; классический Turmoil в консольном создателе отсутствует → `bespokeCanPlay` важен только апстримному спеку; бонус alt-Венеры с 0–4 % недостижим (с L1 Shade до 6 % — только добор 8 %); история шкалы после развёртывания паркуется до ухода стартового workspace (`console-start-hold-param-leave`); добор пролога — батч под корнем розыгрыша.

**A5 · RU и информация.** Описание — «деления», без «уровня кислорода» и «шкалы Венеры», «с аэростатами»; титулы веток — один ключ занят ботом с инфинитивом, двух нет; `cardInformation` — `b.or` «needs curation» + посев описания одним блоком → нужен `infoText` (образец Atmoscoop); спек с опечаткой имени; лора/арта нет.
