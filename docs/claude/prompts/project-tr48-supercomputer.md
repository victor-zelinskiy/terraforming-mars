### Чтение скана (`…\Projects\Card_-_TR48.png`)
Цена **10**, СИНЯЯ рамка (ACTIVE). Плашка у цены — **эмблема Учёных** (колба, «MIN») = ТРЕБОВАНИЕ `{party: SCIENTISTS}`, не метка. Метка справа —
**одна: Наука** (атом). Название «SUPERCOMPUTER». Синее поле — ДВЕ строки: ДЕЙСТВИЕ **→ [data] [data]*** (стрелка без цены слева, ДВА значка data,
звёздочка = «на ЛЮБУЮ карту») → `b.action(…, (eb) => eb.empty().startAction.resource(CardResource.DATA, 2).asterix())`; ЭФФЕКТ **[метка Науки] :

см. EVA). Нижний ряд: **коричневая плашка производства с «− [энергия]»** → `b.production((pb) => pb.minus().energy(1))`. Внизу слева — фиолетовый
символ Turmoil (модуль, без `compatibility`). ПО нет. Лор (напечатан): *«"The answer is... 42!"»* (с кавычками). Подпись арта — «Oak Ridge National

### Правила чтения (каждое — закрепить спеком `tests/cards/turmoilRedux/Supercomputer.spec.ts`)
1. **Требование** — плашка Учёных: правят или 2 СВОИХ делегата на их резолюции; при розыгрыше; TR36 не снижает порог. Wild-метка эффекта Учёных
   требованию не помогает.
2. **Розыгрыш**: −1 пр. энергии; при 0 пр. энергии карта НЕИГРАБЕЛЬНА (правило движка для снижения СВОЕГО производства; причина в руке). Метка Науки
   будит соседей движка (TR05, Olympus Conference, Mars University…).
3. **Действие**: +2 data на ЛЮБУЮ СВОЮ карту-держатель data (свой стол + SRR, никогда чужую), ВКЛЮЧАЯ саму TR48; цель никогда не авто, даже при
   одном держателе (инвариант 3); раз за поколение; держатель есть всегда (сама TR48) → действие всегда доступно (кроме «уже использовано»).
4. **Эффект оплаты**: при РОЗЫГРЫШЕ карты с напечатанной меткой Науки (проект или событие) data С ЭТОЙ карты — оплата по **2 M€** за единицу (плоско);
   data на других картах — нет; wild-метка не делает карту «картой Науки»; стандартные проекты, счета Парламента, колонии, действия карт — НЕ
   «розыгрыш карты Науки» → дорожки нет.
5. **Переплата** — правило движка (как у мехов: курс 2 → «переплата +1» возможна при нечётном остатке); игрок понижает дорожку.
6. **Журнал**: строка оплаты называет data с TR48 (`recordResourceAsPayment`); действие — «added 2 data to X»; Fiber — своя строка M€.
7. **Нотификация соперника**: действие с целью — чип «+2 [data] → <карта>»; оплата data — строка оплаты карты (класс TR09).
8. **Ответы стола на действие**: Fiber +2 M€ (на любую цель); роль цели не меняет ответ.
9. **MarsBot** карту не играет; **save / load** — data — обычные ресурсы карты; новая единица в `Payment` — только в инпутах (проверить, что ни
   один сохранённый `waitingFor` не сериализует `Payment` целиком; иначе — дефолт 0 на загрузке).
10. **Прогноз**: превью розыгрыша — «−1 пр. энергии» + ответы на метку; превью действия — шаг цели с ролями и «что даст +2» (К-T1) + Fiber;
    «Скидки и оплата» эффект-прогноза — новая строка единицы (`paymentValuesOf` сам).

### Решения владельца (по умолчанию — как написано; подтвердить в отчёте, батч — §7)
