## 1. Задача одной фразой

Панель режима голосования Парламента показывает игроку **одно число** — «что я получу при принятии» — с
премиальной припиской **«+N при победе»** внутри того же чтения, источник и цену голоса и два-три честных
факта; вся проза и всё условное уходят в fullscreen-осмотр (X); ни один элемент панели никогда не обрезается
и не скроллится ни на одном из трёх профилей — и это охраняет гард, который не даст следующей резолюции
вернуть перегруз.

## 3. Что должно получиться (вариант A «одна цифра»)

Композиция панели — **ровно четыре вещи**:

1. **Шапка** — имя резолюции + бейдж «Побеждает» (как сейчас).
2. **«ДЛЯ ВАС ПРИ ПРИНЯТИИ»** — ОДНО чтение: контекст `estimate` по текущему влиянию. Для sequel-цепочки
   (Climate Research) — одна строка чипов «[влияние] 2 → +2 [пр. тепла] · [пр. тепла] 4 → 6 → 2 [карты]».
   Рядом — чип ответа правящей партии (`ConsolePartyReaction`), когда он есть. Графика эффекта карты
   (`PremiumMechanicsPanel`) остаётся рядом с числом как «формула» — на всех трёх профилях, если помещается
   в бюджет (на Deck верни её, если после разгрузки есть место; реши по замеру, не по вкусу).
   **Приписка «+N при победе».** Когда победа даёт шаг Повестки с ростом влияния (у `voteYieldsOf` появляется
   чтение `forecast` с `agendaStep`), разница прогноза и оценки показывается ВНУТРИ того же чтения как
   компактный премиальный суффикс-чип: «+1 при победе · шаг 3» (tracked-caps, тихий акцент, глиф шага
   Повестки; `data-hint` с одной фразой объяснения). Нулевая разница (кэп «макс. 5» уже достигнут, шаг без
   роста влияния) — суффикса нет. В sequel-цепочке суффикс считается по каждому звену («+1 [карта] при
   победе»). Суффикс — **не второе чтение**: у него нет своего кикера, своей строки и своего такта.
3. **«ВАШ ГОЛОС»** — одна строка: куб + «из лобби · бесплатно» / «из резерва · 5 M€» (как сейчас) и два
   постоянных факта: «Лидер — → вы», «Побеждает нет → да» (текущее → прогноз; неизменный факт — одно
   значение, без стрелки). Третий факт «Эффект партии для вас» — **только на ребре** (этот делегат даёт
   доступ: «0 из 2 → эффект ваш»); иначе его несут гнёзда `n/2` под картой. Факт «Делегатов на карте» убрать:
   лента кубов под картой и есть этот факт.
4. **CTA с ценой** — как сейчас.

**Уходит с панели → в осмотр:** проза `text.effect/winner/passive/action`; чтения «если победите — шаг N» и
«если принять сейчас» как самостоятельные блоки; блок «Партия резолюции» (эмблема, формула, «всем
игрокам»); блок «Задание председателя»; факт «делегатов на карте».
**Приходит в осмотр** (правая колонка «§ ПРАВИЛА» и/или подвал): блок «ВАШ ГОЛОС» с ПОЛНЫМ прогнозом —
все чтения (`estimate`, `forecast`, «если принять сейчас» с формулой) и все четыре факта; партия и задание
там уже есть. Осмотр — единственное место длинного текста (`.con-zoom-rules`, `max-height: 76vh`).

**Иерархия — типографическая, не позиционная:** число — самый громкий голос (крупная цифра + иконка);
кикер — тихие tracked-caps; суффикс — акцент цветом (партия/amber), но читаемый и без цвета (весом).
**Моушен:** панель приходит той же каскадной фразой входа в режим (`data-parl-vote-late`); у суффикса и
чипов нет отдельного такта; ничего не масштабируется (Ark Nova: calm by default; никаких поп-инов).
**Высота панели:** после разгрузки пересмотри `--con-parl-info-h` в сторону уменьшения, чтобы карты
голосования (главный объект) выросли — но не выше `MAX_VOTE_ZOOM`; реши по замеру на трёх профилях.

## 4. Архитектура правки

- Вынеси построение панели в **чистую модель** `src/client/console/parliament/voteInfoModel.ts`:
  `voteInfoOf(resolution, model, viewer, opts) → VoteInfoVm` (чтение + суффиксы + реакция + факты + источник/
  цена) и `voteInfoBudget(vm) → {kickers, readings, facts, words}`; SFC только рендерит. Суффикс — из
  разницы `forecast − estimate` по данным `voteYieldsOf` (никакого пересчёта влияния руками).
- **Гард** `tests/client/components/console/voteInfoBudget.spec.ts`: для КАЖДОЙ резолюции каталога
  (`allResolutions()` из `@/client/parliament/ClientParliamentManifest`, `copies > 0`; dev-примеры —
  отдельным `describe`) × влияние {0, 1, 2, 5} × {побеждает, нет} × {доступ на ребре, нет}:
  `readings === 1` (реакция не считается), `facts ≤ 2` (+1 на ребре), `kickers ≤ 3`, `words ≤ 28`.
  Провал печатает имя резолюции и что именно превышено — это worklist будущих карт.
- `voteInfoModel.spec.ts`: суффикс появляется только при росте влияния от шага Повестки; нулевая разница →
  нет суффикса; кэп (Architecture / Power Grid «макс. 5» при влиянии 5) → нет суффикса; sequel → суффикс по
  звену; факт доступа — только на ребре; спектатор (не участник) — формула без «для вас».
- **Свидетели для e2e** (`data-*`, никаких текстовых матчей): `data-parl-vote-reading`,
  `data-parl-vote-suffix="<разница>"`, `data-parl-fact="lead|win|access"`, `data-parl-vote-source`; в
  осмотре — `data-zoom-vote-facts`, `data-zoom-vote-reading`.
- **i18n:** новые английские ключи (например «For you when enacted», «+${0} if you win», «Agenda step
  ${0}») — сначала `grep` по ВСЕМ `src/locales/ru/*.json` (сборка падает на дубле), перевод в
  `ru/parliament.json`, `npm run make:json`. Чужие переводы не трогать. Канон: РТ / ПО / метка.
- **Профили:** только токены и раскладка в `console_parliament.less` / `console_tv.less`; никаких `v-if` по
  профилю на содержимое; функциональные состояния — `box-shadow`/`outline`, не `filter` (perf-lite).

## 6. Критерии приёмки (нельзя «почти»)

1. На 1080 / TV 4K / Deck для всех пяти резолюций: `readings === 1`, `facts ≤ 2` (+1 на ребре),
   `kickers ≤ 3`, `words ≤ 28`; ноль элементов с обрезанием, ноль скролл-контейнеров — доказано e2e И твоими
   просмотренными скриншотами.
2. На фикстуре Climate при влиянии, которое победа поднимает, на панели виден суффикс «+1 при победе» внутри
   того же чтения; на Power Grid при влиянии 5 (кэп) суффикса нет.
3. Осмотр (X) из режима голосования показывает всё, что ушло с панели; LB/RB и «A Отправить делегата» из
   осмотра работают как прежде.
4. Карты голосования не стали меньше; если панель ужата — они выросли (замер до/после в отчёте).
5. Стенд «Полигон» рисует те же чтения с суффиксом (модель одна).
6. Зелёные: `npm run lint`, `npm run test:client`, `npm run test:server`, `npm run build:test`, все
   парламентские e2e на трёх профилях (`--workers=1`).
7. Документ `docs/TURMOIL_REDUX_PARLIAMENT_VOTE_ONE_NUMBER.md` (оценка исходного экрана → концепция → что
