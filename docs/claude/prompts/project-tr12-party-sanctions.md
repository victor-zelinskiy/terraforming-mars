### Правила чтения (каждое — закрепить спеком)
1. **Требование** «Requires you to be Chairman» — `requirements: {chairman: {}}` (существующий вид); проверяется при
   розыгрыше: делегат игрока в кресле председателя (Redux — через фасад `politics.isChairman`).
2. **«Discard all neutral delegates from ONE Popular Support Area of your choice»** — игрок выбирает ОДНУ партию из шести;
   ВСЕ нейтральные делегаты её области поддержки уходят в общий запас нейтральных. Нейтральные на РЕЗОЛЮЦИЯХ (голоса) не
   трогаются; делегаты игроков — тоже.
3. **Кандидаты** — области, где стоит ≥ 1 нейтральный делегат. Пустая область ОТКЛЮЧЕНА с причиной («Область пуста»):
   выбор ничего не изменил бы. Область правящей партии — обычный кандидат, если в ней что-то стоит (TR03 может положить
   туда кубы; память `parliament-ruling-party-has-no-support`).
4. **Ни одного кандидата** (все области пусты — частый случай в начале партии) — карта играбельна (печатное требование —
   только председатель), сброс — НАЗВАННЫЙ ПРОПУСК (`recordSkippedEffect`), шаг Карьеры выполняется; композер говорит это ДО
   розыгрыша, двери выбора нет (решение владельца №2).
5. **«Advance your Agenda marker 1 step»** — ОДНА ходьба трека `ChairmanSeat.walkAgenda(player, parliament, 1, {reason:
   'card', card})` с наградой шага (влияние / РТ / карта); конец трека — названный срез (строка уже есть). РТ шага —
   обычный РТ в фазе действий (задание председателя его засчитывает, эффект Зелёных срабатывает — как у TR04).
6. **Порядок — печатный**: сначала сброс, затем шаг Карьеры. Оба — в ответе на ОДИН POST.
7. Председательство после розыгрыша не меняется (карта его не тратит).
8. MarsBot карту не играет; его нейтральные / делегаты не затронуты (кроме общего запаса).

### Решения владельца (подтвердить в отчёте, не блокер)
1. **Хореография = РИТУАЛ КАК У TR03** (выбор ДО отправки, Парламент в зоне руки, A там = POST, исход играет там же,
   геометрия заморожена от A до ухода — закон 8).
2. Пустые области отключены с причиной; ноль кандидатов — пропуск сброса, шаг Карьеры остаётся (правило 4).
3. RU-имя **«Партийные санкции»**.

### B2 · Режим выбора области — `ParliamentStage 'support'`
- Мост: staged-модель входит в `parliamentPromptBridge` источником (как грант TR03), даёт `bridge.supportPick` — тот же

- Поза: ряд оппозиции + плитка правителя — герой (курсор по шести плашкам в порядке ряда, правитель последним или первым —
  как в кольце обзора; d-pad двигает ТОЛЬКО курсор, плашки не двигаются — закон «обзор стоит на месте»). **Трек Карьеры
  виден в этой же позе** (не receded): второй такт играет без смены позы (закон 8 — геометрия неизменна от A до ухода;
  закон 9 — поза влезает в ярус, иначе берёт трек целиком; проверить фит `expectParliamentFits` fhd / tv4k / Deck). Ярусы
  голосования — receded.
- На плашке-кандидате — места поддержки в состоянии «уйдут» (контур вместо заливки на выбранной; на остальных кандидатах —
  тихо) и строка «N → 0»; на пустой — причина. Курсор — рамка плашки; состояние — не цветом одним (закон 11: только то, что
  тронуто).
- Лента (закон 18): кикер **«САНКЦИИ»** (стадия; ключ — `'Sanctions'`, в глоссарий §4/§9), чипы «[эмблема партии] −N».
- Панель чтения под курсором (как панель голоса): партия, «нейтральных в области: N → 0», правило словами одной строкой
  («Делегаты уходят в общий запас. На резолюциях ничего не меняется.»), строка про следующее заседание — только если
  сервер её отдаёт (не выводить последствия на клиенте).
- Команды (`parliamentCommandsOf`, вход `support`): A **«Разыграть карту»** (существующий глагол) · B «Назад» · X

  после. Встроенный Парламент себя не титулует.

### B3 · Коммит и три исхода
`commitStagedTail({type: 'party', partyName, stagedFor: arm.cardName})`. LANDED (область выбранной партии = 0 и
`lastAdvance.seq` вырос с причиной `card`) → B4. RE-ASKED (живой `SelectParty` с `supportPrompt` и
`choiceContext.source.card === arm.cardName`) → стоящий режим становится живой дверью на месте (B «Свернуть»). PARKED
(вклинился чужой промпт) → шаг уходит без тактов, сброс и ходьба приходят обычным обновлением + журнал.

### B4 · Два такта после одного A — один директор фразы
Холды сеются в блоке apply (закон 3; урок TR04): места выбранной плашки держат N кубов, пул запаса — старое число,
`agendaAwaits` + очередь бонусов ходьбы. Затем:
1. **СБРОС**: кубы по одному (≥ 90 мс, ритм закона 12) — прокси рождается невидимым над МЕСТОМ (закон 14), летит в пул
   нейтральных на скамье; место гаснет на отрыве (one-shot), счётчик пула растёт на касании. Порядок — справа налево
   (последний положенный уходит первым). Язык — зеркало посадки TR03 (`supportScene` / `parliamentFlights`), не новый
   полёт.
2. Пауза `BEAT_GAP_MS`.
3. **КАРЬЕРА**: `agendaWalkDirector` N = 1 с часами фразы вызывающего (`AgendaWalkHooks.beat`) — лид сегмента → глайд →
   посадка → награда шага (тик влияния / чип РТ на рельс / сцена `agenda-step` для карты).
4. Чтение → `flow-complete` → `endHandWithHostedStep` (рука и Парламент уходят одной поверхностью).
Именованные холды отпускаются касаниями; потолок реестра — единственная сеть; нет rect → конечная поза + свидетель
деградации. Reduced motion — конечные позы. Задание председателя, закрытое РТ шага, встаёт после ухода (admission

## 7. Режим работы
**4 коммита**, каждый зелёный по юнитам: (1) сервер — `discardPopularSupport` + событие, шаг `DiscardPopularSupport` с
близнецом и маркером, адресный `party`-хвост, причина председателя + спеки; (2) карта + превью + локаль + арт + лор + спеки;

`npm run lint`, `npm run build:test`, `npm run make:cards`, `npm run make:json`; перед визуальной проверкой `npm run make:css`
+ `npm run build:server`. **Не пушить.**
