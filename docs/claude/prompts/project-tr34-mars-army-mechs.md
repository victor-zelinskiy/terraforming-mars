**Что это за карта.** Синяя, два варианта одного действия: **A** — заплатить 1 энергию, +1 мех сюда (действие TR09 / TR11

data). Розыгрыш кладёт 1 мех. Сестра TR35 Mars Army Ships — то же с титаном и истребителями. Значит, главная серверная работа —
**обобщить `censusAction.ts` в модуль со СПЕКОЙ** (ресурс · вариант A с ценой или без · цена B), чтобы TR15 / TR24 остались
побайтно, а TR34 / TR35 получили действие одной декларацией. Главная клиентская работа — **подача момента «мех покупает
делегата»** (§2 B2) и приёмка класса PL-099 / PL-063 на варианте A.

### Правила чтения (каждое — закрепить спеком карты)
1. **Требование** — Красные (у власти или 2 ваших делегата на их резолюции); условие розыгрыша; действие работает при любом
   правительстве.
2. **Розыгрыш: +1 мех на эту карту** (декларативно `behavior: {addResources: 1}`); больше ничего.
3. **Одно действие, два варианта, печатный порядок:** A — 1 энергия → +1 мех сюда; B — 1 мех отсюда → 1 делегат ИЗ РЕЗЕРВА на
   резолюцию области голосования (закон гранта: бесплатно, куб лобби не тронут, без поддержки).
4. **Доступность:** A ⇔ энергия ≥ 1; B ⇔ мех здесь ≥ 1 ∧ есть резолюция на голосовании ∧ делегат в резерве — ОДНА причина
   по порядку (мех → область голосования → резерв). Один живой вариант — всё действие (без `OrOptions`); два — `OrOptions` с
   `effectChoice`. Оба мертвы — причина, на которую игрок может повлиять (правило TR66).
5. **Цена B уходит В ответе шага**: после перечтения резерва, перед посадкой куба (CHECK → PAY → PLACE); мех, ушедший между
   вопросом и ответом, — ни куба, ни списания.
6. **Делегат — обычный:** голоса, эффект партии при двух, требование партии, задание председателя «отправить N делегатов»,
   требование TR02.
7. **Мехи здесь — не деньги и не ПО:** единицы `mechs` / `constructionMechs` читают только свои карты; дверь торговли TR66 читает
   только свою; мехи Весты / TR29, положенные сюда, — топливо B.
8. **Порядок событий:** A — энергия списана → мех добавлен; B — мех снят (цена) → `delegates-placed`. Все записи под источником
   карты.
9. **Раз в поколение**, как у любой синей; «Действие использовано» — обычный флаг.
10. **Save / load**: счётчик и флаг действия.
11. **MarsBot** карту не играет.
