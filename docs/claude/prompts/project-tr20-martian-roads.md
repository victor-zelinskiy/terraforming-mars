# Промт исполнителю · TR20 Martian Roads («Марсианские дороги») — карта, вся ценность которой — ПО за метки

Выдан 2026-10-03. Инфраструктура набора стоит (TR01–TR13, TR15–TR19, TR66 сданы) — **ничего из неё не повторять.**
Процедура — `docs/claude/turmoil-redux-card-checklist.md`, журнал — `docs/claude/turmoil-redux-cards-progress.md`, правила
карт — `.claude/rules/game-logic.md`, сервер — `.claude/rules/server.md`. Номера строк сняты с HEAD `ac8cbe3136` (дерево
чистое) — перед правкой перечитать.

**Новых игровых механик нет.** У карты нет эффекта: требование «Марс вперёд» (класс TR15), метки Марс + Строительство и
**1 ПО за каждые 3 метки Строительства** — стандартный `victoryPoints: {tag, per}`. Но именно поэтому вскрывается одна
дыра общего слоя, и закрыть её — главная работа задачи: **композер розыгрыша про ПО «за метки» пишет «Победные очки: по
условию»** (`consolePlayCardResult.ts:119–138` — любой не-числовой `victoryPoints` = `variable`). Для этой карты это вся её
ценность, спрятанная за двумя словами, — хотя число вычислимо до розыгрыша (собственная метка карты уже учтена движком) и
сервер уже умеет объяснять его формулой в обозревателе счёта.

| Впервые | Что это | Образец (уже в коде) |
| --- | --- | --- |
| **Первая карта набора без графики эффекта** | лицо = плашка требования + метки + арт + бейдж ПО; панели механик нет | `NO_MECHANICS_ACCEPTED` (`tests/client/components/premiumCard/premiumCardViewModel.spec.ts:546–555`: Advanced Ecosystems, Interstellar Colony Ship — у них нет `renderData` вовсе) |
| **ПО «за метки» с делителем > 1 в скоупе** | бейдж «1 / 3 [Строительство]» | `vpRelationOf` (`premiumCardViewModel.ts:320`): `per` + `target` → «N / K [icon]» |
| **Проекция ПО карты при розыгрыше** (класс) | композер говорит «+2 · [метка] 7 / 3», а не «по условию» | `computeCardVpMechanics` (`src/server/game/calculateVictoryPoints.ts:153–205`, сейчас приватная) + `formulaFor` / `formulaText` обозревателя счёта (`scoreExplorerModel.ts:510`, `ConsoleScoreExplorer.vue:722–761`) |
| **Лор с нотами** | «♪ Country roaaaaads, take me hooooome... ♪» — оканчивается не пунктуацией | гард `every lore text ends with terminal punctuation` (`premiumCardViewModel.spec.ts:727–732`, `/[.!?…]$/`) |

### Правила чтения (каждое — закрепить спеком)
1. **Требование** «Requires Mars First to be ruling or that you have 2 delegates there» = `requirements: {party:
   PartyName.MARS}` (подача — класс TR15: эмблема в плашке MIN, причина «N из 2», компакт руки).
2. **ПО** = `victoryPoints: {tag: Tag.BUILDING, per: 3}` — `floor(метки / 3)`.
3. **Собственная метка Строительства считается** (после розыгрыша карта в табло; до него `Counter` добавляет метки ещё не
   сыгранной карты — `Counter.ts:152–156`, `cardIsUnplayed`).
4. **Счёт меток ПО — «сырой»** (`Counter.count(…, 'vps')` → `tags.count(tag, 'raw')`, `Counter.ts:151`): ДИКАЯ метка НЕ
   считается; метки СОБЫТИЙ не считаются (кроме режима, где движок держит их в игре, — его правило, не наше); надбавка
   резолюции R&D Funding (RX26) в счёт ПО не входит по построению (только `default`).
5. **Значок ПО — неотрицательный переменный** (`victoryPointsIconOf` → `{kind: 'variable', sign: 'nonNegative'}`,
   `common/cards/victoryPointsIcon.ts`). Следствия, ничего не программировать — ЗАКРЕПИТЬ: при TR16 «Административный
   район» в табло розыгрыш TR20 даёт +1 карту (прогноз == исполнение); резолюция «Architecture Award» (RX02) считает TR20.
6. **Карта с требованием партии** — у TR13 «Политический аналитический центр» в колоде становится на одну цель больше
   (`partyRequirementCardsInGame` выводит сам; ни один спек числа не пинит).
7. «Дороги» — только флейвор: никакого тайла (не путать с дорогами Луны).
8. MarsBot карту не играет.

### Решения владельца (подтвердить в отчёте, не блокер)
1. RU-имя **«Марсианские дороги»**.
2. **Проекция ПО в композере — делать** (блок B): для ПО «за метки» композер показывает число, которое карта принесёт в
   момент розыгрыша, и формулу. Скоуп класса — ТОЛЬКО метки (`unit === 'tags'`): их счёт розыгрыш не меняет ничем, кроме
   собственных меток карты; ПО за ресурсы, города, соседство (`nextToThis`), колонии и `special` остаются «по условию» —
   там число зависит от того, что розыгрыш ещё сделает.
3. **Лор — дословно со скана, с нотами** (EN — ключ `"TR20"`), гард пунктуации учит ОДНУ узкую форму: терминальная
   пунктуация + закрывающая нота песни (`/[.!?…](\s*♪)?$/` или эквивалент — ноту можно снять ровно один раз и проверить
   остаток). RU: **«♪ Просёлочные дорооооги, отвезите меня домооооой... ♪»** (растянутые гласные — шутка скана).
4. **Арт** — файл `C:\Users\zelin\Downloads\Mars Arts\Извилистая дорога среди марсианской пустыни.png` (1536×1024,
   положен 2026-10-03 15:47, тот же сюжет, что на скане) считается артом TR20. Файл владельца НЕ переименовывать; если
   скрипт импорта спотыкается о кириллицу в пути — скопировать во временный ASCII-путь вне репозитория.

## 3. Блок B · проекция ПО карты при розыгрыше (класс «ПО за метки»)

### B1 · Сервер — одно чтение, тот же источник, что у счёта
- `computeCardVpMechanics(player, card)` (`calculateVictoryPoints.ts:153`) — ЭКСПОРТИРОВАТЬ, не копировать. Рядом —
  `cardVictoryPointsAtPlay(player, card): CardVictoryPointsDetail | undefined`: `{cardName, victoryPoint:
  card.getVictoryPoints(player), kind: classifyCardVictoryPoints(card, vp), mechanics}` — ТОЛЬКО когда `mechanics.shape ===
  'per' && mechanics.unit === 'tags'` и `nextToThis` отсутствует; иначе `undefined`. Тип — тот же
  `CardVictoryPointsDetail` (`common/game/VictoryPointsBreakdown.ts:54`), что читает обозреватель счёта: «как карта
  считается сейчас» и «как карта будет считаться в табло» — одна форма данных. Чтение — чистое (`Counter` ничего не
  мутирует; спек — снимок до/после).
- Поле `ActionPreview.cardVictoryPoints?: CardVictoryPointsDetail` (`ActionPreviewModel.ts:58`, рядом с `forecast :86`) —
  едет В ТОМ ЖЕ ответе, что прогноз эффектов: `CardPlayPreview.ts:79` →
  `{...preview, forecast: …, cardVictoryPoints: cardVictoryPointsAtPlay(player, card)}`. Нового запроса, нового маршрута,
  новой записи в CORS нет; кэш — тот же ключ версии. Действия (`ActionPreview.ts:58`) не трогать — синие карты уже в табло.
- **Гард паритета** `tests/models/cardVictoryPointsAtPlay.spec.ts`: перебрать ВСЕ карты премиум-скоупа (SCOPE как у
  `cardPlayPreviewCoverage`) с `victoryPoints` по меткам; на столе, где у игрока есть совпадающие метки, ДИКАЯ метка и
  событие с той же меткой, — проекция до розыгрыша `===` `getVictoryPoints(player)` сразу после `playCard` +
  `runAllActions` (ответить на промпты, если карта их задаёт); анти-вакуумный пол ≥ 3 карт (Ganymede Colony, Io Mining
  Industries, Water Import From Europa … + TR20) — печатает расхождения по имени.

### B2 · Клиент — один словарь формулы
- Форматтер формулы — ЧИСТЫЙ и ОДИН: `formulaText` / `remainderText` / `formulaTagIcon` переезжают из
  `ConsoleScoreExplorer.vue:722–761` в `scoreExplorerModel.ts` рядом с `formulaFor` (экспортировать); обозреватель счёта
  читает их оттуда побайтно как прежде (его спек зелёный без правки ожиданий).
- `victoryPointSection(meta.victoryPoints, projection?)` (`consolePlayCardResult.ts:119`): есть проекция → строка ПО
  несёт ЧИСЛО «+N» (в т. ч. **«0»** — для карты, чья вся ценность ПО, ноль — это ответ, а не повод скрыть строку) и
  формулу из общего форматтера: значок метки · «7 / 3» · «ещё 2 до следующего ПО» (когда остаток > 0). **Число печатается
  один раз** (формула без «= N ПО» либо число — внутри формулы; не оба). Слово-квалификатор «сейчас» — число вырастет
  вместе с метками. Нет проекции → прежнее «по условию», побайтно.
- Композер (`ConsolePlayCardConfirm.vue:259–272`, `vpDetail :2307`) — только отрисовка готового; ни одного подсчёта
  меток на клиенте. Строка не растёт в высоту (одна строка на fhd / 4K / Deck — замерить; длинная формула режется
  многоточием В СВОЁМ боксе, а не переносом).
- Приватный счёт (`privateScoreState`) строку не маскирует — как не маскирует фиксированное «+1»: это вклад карты, а не
  счёт игрока; скрытые ПО соперников (`showOtherPlayersVP`) не затронуты — проекция только своя.

## 7. Режим работы
**3 коммита**, каждый зелёный по юнитам: (1) карта + спек + локаль + лор (+ гард ноты) + арт + строка
`NO_MECHANICS_ACCEPTED`; (2) проекция ПО — экспорт серверного чтения, поле превью, гард паритета, переезд форматтера,
строка композера + юниты; (3) журнал набора (+ строка чеклиста §4: «ПО за метки → композер читает
`ActionPreview.cardVictoryPoints`, ничего в файле карты»). Перед каждым: `npm run lint`, `npm run build:test`,
`npm run make:cards`, `npm run make:json`; перед визуальной проверкой `npm run make:css` + `npm run build:server`.
**Не пушить.** Документ карты не заводить. Гочи: `python3` — заглушка Store; юниты последовательно; `eqeqeq` без
исключения для null.
