Возможные дефекты — проверить каждый: ① ответ рассказан ДВАЖДЫ (сторож `[transfer] told twice`); ② ответ не рассказан никем — ряд титана тикает в кадре применения вида; ③ ответ рождается ПОСЛЕ переворота — на метке карты, которая уже лежит рубашкой (источник не нарисован — сторож `[transfer] end not painted`); ④ реактор — КОРПОРАЦИЯ, а розыгрыш идёт из «КАРТЫ В РУКЕ»: лица корпорации на экране нет (класс GF — «место, не показывающее карту, — не место»); ⑤ взлёт не ждёт ответа — событие уходит под жетоном, который на него ссылается.

**A6 · (ОБЛАСТЬ) Цена и ответ в ОДНОМ ряду.** Космическое событие оплачено титаном (жетон цены уходит с ряда титана первым — PL-107), ответ Palladin приходит титаном в тот же ряд. Проверка обещания рельса знает «известные ходы ряда» (`railReward.ts:273`; цена розыгрыша передаётся `paid`) — по коду дорога ДОЛЖНА сходиться, но это первый реактор в скоупе, у которого ряд ответа совпадает с рядом не-M€ цены: если известный ход цены до проверки не доезжает, ряд «движется иначе» → обещание не держится → титан прыгает «5 → 3» одним кадром вместо «5 → 2 → 3».

**A7 · (доказать, не строить) Действие поднимает температуру до ПОРОГА.** Шаг на −24 / −20 °C даёт производство тепла, на 0 °C — океан: у синего действия это размещение СЛЕДУЮЩИМ шагом после ухода workspace, и история шкалы обязана сыграть ДО сетки размещения (блок допуска `board-story`). Дорога общая (GHG Producing Bacteria), стенда порога из синего действия — проверить, есть ли.

**A8 · (доказать, не строить) Старт.** «5 [титан]» — ОДИН печатный значок с цифрой: пять единиц приходят с одного значка; ряд титана обязан тикать на касаниях.

## Правила карты (пинятся спеком; не переоткрывать)

1. **Старт:** 36 M€ и 5 титана; метка КОСМОС (считается везде, где считаются метки корпорации; сама корпорация — не событие и свой эффект не будит).
2. **«Космическое событие»** = тип карты СОБЫТИЕ **и** печатная метка КОСМОС (`card.tags`). Космическая карта не-событие — нет; событие без метки космоса — нет. Счётные «любые метки» (эффект Учёных Redux) событие космическим не делают.
3. **«Когда ВЫ разыгрываете»:** только свои розыгрыши, любой дорогой, которой карта попадает на стол через `playCard` (рука; розыгрыш через закон, если достижим). Чужое событие, флип бота — нет.
4. **Титан эффекта приходит ПОСЛЕ оплаты** — им нельзя заплатить за событие, которое его породило. Один титан за карту, сколько бы меток у неё ни было.
5. **Действие:** 2 титана → температура +1 шаг; раз в поколение, как всякое действие карты. Цена — ДВЕ ЕДИНИЦЫ ресурса, не M€: ценность титана (Phobolog, Advanced Alloys, закон RX19) её не меняет. Шаг — рейтинговый по общему правилу движка (РТ, бонусы трека, океан на 0 °C — своё размещение игрока).
6. **На максимуме температуры** действие по правилам доступно и ничего не даёт — в форке это «действие без эффекта» (показано приглушённым внизу, активируемо, причина до нажатия); под законом RX35 судится по замещению. Не блокировать.
7. **Красные классики** — по апстримному спеку (`:35–46`), не трогать. Redux: что бы ни делала политика стола с рейтингом шага (вето RX42, замещение RX35, пропуск P57), действие читает это через общие двери — спек называет каждую.
8. **MarsBot:** человеческая Palladin и бот-двойник C43 на одном столе не встречаются (коллизия по `original`); двойник не трогается. Вторая корпорация (Merger): эффект и действие — с момента розыгрыша.
