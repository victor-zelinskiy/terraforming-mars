## 1. Материал — эмаль Комитета, не бумага

| Зона | Материал | Почему |
| --- | --- | --- |
| Плита карты | глубокий **петроль** `#133843` (эмаль с тонкой гравировкой-штриховкой) | свой цвет Комитета: не совпадает ни с одной лентой типа карт и не тонет в тёмно-синей сцене |
| Кромка | **металл ранга** — золото · сталь · бронза · ржавчина (азартный) | ранг читается материалом, шевроны дают форму; кромка рисует силуэт на тёмном столе |

У каждого металла две краски: яркая на эмали (`--tm`), глубокая на керамике (`--tm-deep`).
Состояния — материалом (VISUAL RESTRAINT): взятый / изъятый / выкупленный — эмаль и окно сереют, металл тускнеет, арт
обесцвечивается; штамп на керамике. Ни одного стоячего свечения (ратчет `glowRestraintGuard` не вырос).

## 2. Раскладка — один макет на всех размерах

`ТЕНДЕР` + печать семейства + `№ 04` → окно арта → табличка (имя по лестнице `data-name-tier` · строка ранг/окно ·
перфорированный корешок «НЕ ИСПОЛНЕН → 3 M€»). Все длины внутри в `em`, `em = --tender-w / 14` — `table`, `reader`,
портфель (11rem) и вьюер (23rem) — один и тот же макет в масштабе. `plaque` (герб места на подиуме) — шапка и имя на
эмали, без окна и корешка.

**На лице нет прозы ни на одном размере.** X открывает ОДИН вьюер (`TenderZoomEntry`): справа — панель правил
проектной карты (`ConsoleCardRulesPanel` + `tenderAnnotations`: «Эффект тендера» · «Когда исполняется» · «Если не
исполнен»), слева — лор в архивном блоке (`tenderLoreModel`). Оба хоста вьюера (оболочка партии и предыгровой
`ConsoleMenuZoomHost`) — одна ветка.

## 3. Обложка — `ConsoleTenderBack`

Та же эмаль, двойная **золотая** кромка (силуэт на тёмной сцене), в центре печать Комитета — планета с кольцом над
линиями горизонта, слово «ТЕНДЕР», «Терраформирующий комитет». Общая для стопки «Реестра тендеров» и рубашки
сдаваемого лота. Контейнер размеров: краска на ДОЧЕРНЕМ элементе — `cqw` резолвится от предка-контейнера, и
собственная длина контейнера в `cqw` мерила вьюпорт (первый кадр 4K нарисовал «Реестр» золотым стадионом).

## 4. Арт — как подключить

Файл `assets/campaign/tenders/<id>.webp` (`node scripts/import-tender-art.mjs <id>` — обрезка 4:3, 1200×900, WebP), затем строка `<id>: true` в `TENDER_ART`
(`tenderArt.ts`). До этого окно гравирует глиф семейства — заглушка по построению, никакого 404.
`object-fit: cover` — важное держать в центральных ~80 % кадра.

## 5. Бриф арта (этап 2) — СЕМЬЯ «ЧЕРТЕЖИ КОМИТЕТА»

Владелец (2026-11-08, после первого рендера «Пересмотра проектов» — 3D-клешня держит карту-чертёж, «странно»):
**каждый арт — узнаваемый ЧЕРТЁЖ**. Тендер — техзадание Комитета, его арт — лист технической документации. Семья
держится одним языком, узнаваемость — СИЛУЭТОМ предмета: у каждого вида свой предмет, ни предмет, ни силуэт не
повторяются (таблица ниже — план до рендеров, уникальность по построению).

**Язык чертежа (общий для всех 12):**
- Лист — чертёжная плёнка в ПЕТРОЛЕ лица (`#0f2e37 → #133843`) с тонкой бледной сеткой; не ярко-синяя «синька» — она
  спорит с эмалью карты.
- Линии — бледно-циановые/белые (`#cfe8ec`), ДВЕ толщины: жирный контур силуэта и тонкие детали; штриховка для
  объёма, выносные/размерные линии со стрелками БЕЗ цифр. Вид — изометрия / ¾: предмет объёмный, но нарисованный.
- **ОДИН сплошной акцент** — залитый элемент в металле ранга (золото `#dcbc7c` решающий · сталь `#b9c6d1` весомый ·
  бронза `#d39b6b` малый · ржавчина `#e27a5c` азартный): он и есть МЕХАНИКА вида (что оставлено / добавлено /
  перетасовано). Всё остальное — линии.
- Один предмет (+ максимум один вторичный), ~55–65 % высоты кадра, важное в центральных 80 %; читается в окне
  ~250 px. Без текста, букв, цифр, логотипов, людей, пейзажа, свечения.
- Кадр 4 : 3, 1600 × 1200 PNG; выход — `C:/Users/zelin/Downloads/Mars Arts/tenders/<id>.png`; импорт —
  `node scripts/import-tender-art.mjs <id>` → `assets/campaign/tenders/<id>.webp` + строка в `tenderArt.ts`.
- Семейные подсказки внутри предмета: ПРОЛОГ = запечатанный конверт-депеша, ПРОЕКТ = лист-чертёж / рулон,
  КОРПОРАЦИЯ = башня штаб-квартиры.

**Урок двух рендеров (2026-11-08) — что делает чертёж УЗНАВАЕМЫМ.** «Пересмотр проектов» (кнопка прижимает лист)
читается с одного взгляда; «Пересмотр прологов» (стеллаж-ячейки с одним конвертом) владелец назвал «чертёж непонятно
чего». Разница не в языке, а в ГЕРОЕ:
1. **Герой — ИКОНИЧНЫЙ предмет, который любой назовёт одним словом по одному силуэту** (кнопка, ракета, кости, рулетка,
   кран, портфель, шахматный конь). Никогда — ёмкость / сетка / мебель, смысл которой зависит от того, что в ней есть
   или чего нет (стеллаж, полка, лоток, таблица): такой чертёж читается как «схема шкафа».
2. **Акцент залит НА САМОМ герое и крупно** (кнопка целиком), а не мелкой деталью внутри фона (печать на конверте).
3. **Акцент контрастен линиям.** Сталь близка к цвету линий — её заливать как металл с размахом тона (тёмный
   гунметалл `#5f6d7a` → блик `#dfe7ee`), чтобы залитое тело никогда не читалось как ещё одна светлая линия.
4. Герой — ≥ 50 % высоты кадра; механика (что ушло / пришло) — 2–3 пунктирных силуэта со стрелками, не больше.
