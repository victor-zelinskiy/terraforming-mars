## 4. Выводы для промта (внесены)

1. **Целевой сценарий стенда — Redux · Hard · все дополнения** (`--target=redux`), не «Hard без Redux». Полоса на холдинг поднимается до **p50 14–18** (пара ≈ 30–34) — верхняя граница ориентира владельца «+20…30» становится серединой. Это решение владельца (D8 в промте): при полосе 10–14 бот в Redux остаётся при −12.
2. Дивиденды закрывают разрыв миссий 2–4, но **миссию 1 в Redux (−3) не трогают** — там портфель пуст. Если и там нужен паритет, это отдельный рычаг (не дивиденд).
3. Миссия 2 даёт боту ОДИН холдинг (+15) при разрыве −38 — выравнивание полное только к миссии 3. Альтернатива (D1): оба холдинга сразу на миссии 2.
4. Две клаузы переделать по форме, не по ставке: C34 Stormcraft (нет источника флоатеров без основной) и C39 Utopia Invest (вершины треков недостижимы в партиях на 7–9 поколений). C01/C21/C17/C44 — правка ставки (указана в таблице).
5. Короткие партии Redux (7–9 поколений) означают: клаузы на «объём» (стопка, позиции) дают меньше, клаузы на «плотность» (соседства, пары, награды) держатся. Формы СОСЕДСТВО / ПАРЫ / ПИК-по-наградам — самые устойчивые к Redux.
