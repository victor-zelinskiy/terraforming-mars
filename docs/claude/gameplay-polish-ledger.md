# Реестр полировки игрового процесса (`PL-###`)

Постоянный документ набора Turmoil Redux. Заведён 2026-10-05 картой **TR26 UNMI Liner** — первой задачей по схеме
«80 % карта + 20 % ПОЛИРОВКА ПО ПУТИ». Правила схемы (скоуп, два рода находок, метод осмотра, критерий «сейчас /
записать», порядок P0–P4, дисциплина правки) — `docs/claude/turmoil-redux-card-checklist.md` §7; здесь только строки.

**Скоуп:** игровой процесс консольного шелла — поле, рельсы, рука, композеры, workspaces, сцены и полёты, журнал и
нотификации в партии, досье, строка команд, тексты. НЕ сюда: меню, лобби, создание партии, кампания, настройки,
системное меню, dev-инструменты, Electron, остатки десктопа, «решения владельца по умолчанию».

**Строка:** `PL-###` · дата · кто нашёл · поверхность · род (Д — дефект: неверно или сломано · С — слабость: работает, но
не премиум) · тяжесть (S1 ломает или лжёт · S2 видно каждому каждый раз · S3 видно иногда · S4 вкус) · описание +
воспроизведение + доказательство · класс причины · статус.

**Статусы:** `открыта` · `исправлена <коммит>` · `ждёт владельца` (что именно решить) · `не чиним` (почему).
Находка без доказательства и шагов воспроизведения не записывается; строка, перенесённая из журнала набора, несёт
пометку, КАК она перепроверена на дереве в день переноса: **«код ✓»** — гэп виден в коде сегодня; **«журнал»** —
перенесена по записи карты, опровержения в коде нет, глазами в этой задаче не воспроизводилась (следующая карта на этом
маршруте сперва воспроизводит).

Следующий свободный номер — в конце файла.
