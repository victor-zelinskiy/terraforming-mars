## 3. Примитивы (Ф1)

- **`readSettled(page, read, {equal = 2, timeoutMs, settle = true, same, message})`** — `settledRead.ts`. `settle`, затем
  ридер (Node-сторона, может звать `page.evaluate`) до `equal` равных чтений подряд; между чтениями — ДВА кадра (или
  100 мс без идущих анимаций на тихой странице). Таймаут печатает последние чтения. Внутри цепочки (стоит блокирующий
  холд) — `{settle: false}`. Округляй то, что сравниваешь.
- **`armWitness(page, key, reader, {args, settled, max, rafTick})` → `Witness`** — `witness.ts`, поверх
  `recordTransient`: `samples()` · `values()` · `last()` · `ever(pred)` · `firstWhere(pred)` · `sequence(map)` ·
  `happenedInOrder(map, expected)` · `waitFor(pred, {timeoutMs, message})` · `stop()`. Ридер — в странице,
  самодостаточный, возвращает НАБЛЮДЕНИЕ (JSON), не счётчик своих вызовов; идентичность элементов — `WeakMap` на
  `window` внутри ридера. `witnessOf(page, key)` — вопросы к записи, взведённой в другом месте. Переживает перезагрузку.
- Чистая половина (`observeCore.ts`: `settledValue`, `firstWhere`, `sequenceOf`, `inOrder`) — под серверным раннером
  (`tests/console/observeCore.spec.ts`).

## 4. Рецепт миграции спека (меняется КАК он наблюдает, НЕ ЧТО он утверждает)

Перед правкой: `tsx tests/console/e2eFlakeScan.ts --census` — счёт файла по классам; прочитать `.claude/rules/tests.md`.

1. **B — сэмплер (`setInterval` / `requestAnimationFrame` в спеке, обычно `MutationObserver` + `setInterval` в
   `page.evaluate`, копящий состояние в `window.__x`).** Переписать на `armWitness`: ридер возвращает НАБЛЮДЕНИЕ текущего
   кадра (есть ли элемент, его атрибуты, позиция), а свёртка (счётчики «сколько раз», «первый раз», «порядок») делается
   на Node-стороне по `values()` / `samples()`. Счётчик ТИКОВ («видели в 3 сэмплах») — это число кадров, утверждение о
   машине: переводить в «было ли» / «первый раз» / порядок. Сосуществование/порядок («никогда двух сразу», «старое ушло
   до нового») — `{settled: true}`. Элемент, который надо считать один раз, — `WeakMap` первого появления в ридере.
   Время — `t` сэмпла (часы страницы).
2. **G — `waitForTimeout`.** Определить, ЧЕГО ждёт пауза: экран в покое → `settle(page)` (или ничего: `press` уже ждёт
   тишины); появление/уход → ассерт локатора с таймаутом; значение → `expect.poll`; эффект нажатия → `pressUntil`.
   Тик опросного цикла в спеке → переписать цикл на `expect.poll` / `pressUntil`. Пауза посреди кинематики (кадр
   середины полёта в тайминг-спеке) — `cinematicBeat(page, ms, 'почему')`. Внутри обязательной цепочки (стоит
   `[blocking]` холд) — не `settle`, а ожидание СЛЕДУЮЩЕГО шага (его поверхности / `promptId`).
3. **A — `expect(await x.count()).toBe(n)` и т.п.** → `await expect(x).toHaveCount(n)`, `toBeVisible()`/`toBeHidden()`,
   `toHaveText`/`toContainText`, `toHaveAttribute`; производное значение → `await expect.poll(() => …, {message,
   timeout}).toBe(…)`. Сообщение сохраняется. Отрицательная проверка «никогда не появлялось» — это НЕ разовое чтение,
   а запись: `armWitness` до действия + `ever` после.
4. **C — геометрия.** Замер после действия → `readSettled(page, () => …)`; сравнение двух замеров — ОБА через
   `readSettled`. Замер переходного (позы посреди полёта) — в ридере `armWitness`. Ридер, объявленный в файле и
   названный внутри `readSettled(…)`/`armWitness(…)`, считается домом.
5. **H — `Date.now()` драйвера в `expect`.** Длительность в функциональном спеке — по часам страницы: `t` сэмплов
   рекордера (`firstWhere(…).t - firstWhere(…).t`) или `data-*-at` продукта. Если утверждение «быстрее N мс» — суть
   спека, спек тайминговый (`timingSpecs.ts`, с причиной). Длительность в СООБЩЕНИИ (диагноз) — не класс.
6. **E — «исчезло ⇒ готово».** Рядом с ожиданием ухода — правда сервера (`wireOf`/`fetchPlayerModel`, `promptId`
   транспорта, `syncClient`, `placementState`).
7. **D — слепые нажатия.** «A пять раз», `expect.poll(async () => { await press(…); return … })` → `pressUntil(page,
   key, done, {settleMs})` (повтор только если эффекта нет ЦЕЛЫЙ промежуток).

8. **Порог «живости» сэмплера** («the probe sampled: > 40») — после перевода на запись считает РАЗЛИЧНЫЕ состояния,
   а не кадры: ставить `> 0` (ловит только мёртвый рекордер — `tests.md`), реальные утверждения спека судят сами.
9. **Тайминг-свидетель, которому нужно отличить тихий экран от стоящего главного потока** (дырка в серии = поток
   стоял): `armWitness(…, {tickMs: 8})` + ридер, штампующий каждый вызов (`t: performance.now()`, не чаще раза в
   4 мс — иначе одинаковое значение не пишется); серию брать из записи как есть, никогда не «дорисовывать» пробелы
   (`console-play-landing-geometry`). Без `tickMs` пробел в записи — это «ничего не менялось», не «поток стоял».
10. **Длительность — `pageNow(page)` до действия, `t` сэмпла после** (`witness.ts`), см. п. 5.
11. **Перф-пробы** (`*perf-probe*`, раскадровки): пауза, которая и есть предмет («посидеть N с и померить кадры»,
    кадр середины полёта), — `cinematicBeat(page, ms, 'почему')`; всё остальное — ожидание состояния.
12. **Внутри обязательной цепочки** (стоит `[blocking]` холд до следующего ответа) — `settle` бросит: ждать
    поверхность следующего шага / `promptId`; `readSettled(…, {settle: false})`.

После правки: `npx tsc -p tests/e2e/tsconfig.json --noEmit`; счёт файла упал; `npm run e2e:baseline`; страж
`npx mocha --import=tsx --require tests/testing/setup.ts tests/console/e2eDriverGuard.spec.ts`; затем спек на боксе в
CI-профиле: `TM_E2E_CI_LIKE=2 npm run e2e:remote -- <task> <spec> --workers=1 --retries=0 [--repeat-each=N]`.

**Запрещено** (промт § 6): ослаблять утверждение, поднимать таймаут как «фикс», ретраи / `test.retry` / `if (CI)`,
`test.skip`, `waitForTimeout` в спеке. Красный, который оказался гонкой продукта, — баг продукта: чинить продукт (с

Бокс (обычный режим, `fz-flake2`, против `19a755ac2b`): 63 + 32 зелёных, 7 красных — разобраны:
- ⭐ **ВТОРОЙ НАСТОЯЩИЙ ДЕФЕКТ ПРОДУКТА, найденный записью** (4 красных одной причины — `effect-decision-embed` ×2,

  follow-up), — и на эту задачу оверлей переезжал к `body` в СТАНДАРТНОМ (полноэкранном) облике, пустой. Кадр,
  попавший в эту щель, мигал полосой. Сначала наблюдение было уточнено до факта («полоса» = оверлей без
  `--embedded`, «карта на экране» = невзятая карта) — красные остались: это продукт. Починка: оверлей, показывавший
  набор встроенным и потерявший хоста с пустым набором, сохраняет встроенный облик и ничего не рисует
