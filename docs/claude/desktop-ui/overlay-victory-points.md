## Victory Points overlay (the "ПОБЕДНЫЕ ОЧКИ" overlay — endgame scoring analytics)

The bottom-bar **VP** counter button (`activeOverlay === 'victoryPoints'`) opens `src/client/components/overview/VictoryPointsOverlay.vue` — a premium dark-glass score report (frame / L-corner ticks / hero count-up shared with the other overlays). It reads `displayedPlayer.victoryPointsBreakdown`; the **hidden** state (other players' VP mid-game) is preserved (`!showOtherPlayersVP && displayedPlayer !== thisPlayer`).

**Three reading levels:** (1) hero grand total; (2) **breakdown BARS** — the headline analytics; (3) per-bar **legend+detail** cards + the multi-column **"from cards"** list.

**The BARS share ONE px-per-VP scale** (`model.maxScalePositive`) so their LENGTHS are directly comparable at a glance ("what carried the game"); each bar splits into colour SEGMENTS. There are **4 core bars + conditional expansion bars**:
- **РТ** (`tr`) — segments `Стартовый РТ (base)` · `температура` · `кислород` · `океаны` · `Венера` · `карты и эффекты`.
- **Карты** (`cards`) — positive segments by VP family `ресурсные` · `условные` · `фиксированные`, plus a red striped **penalty** deduction segment.
- **Города и озеленение** (`board`) — `города` · `озеленения`.
- **Достижения и награды** (`mca`) — `достижения` · `награды`.
- Conditional extras (only when the expansion is on AND non-zero): **Moon** (habitats/mines/roads), **Planetary tracks** (Pathfinders — these were the unlabelled "шкалы"), **Escape Velocity** (penalty).

**Layout pipeline = a PURE, unit-tested builder `src/client/components/overview/victoryPointsModel.ts`** (`buildVictoryPointsModel(breakdown, {hasMoon, hasPathfinders, hasEscapeVelocity})` → `{scales, maxScalePositive, cardGroups, grandTotal}`). No Vue/DOM/i18n in it (labels are English i18n KEYS the component translates). The "from cards" `cardGroups` are grouped by `kind`, **positives sorted desc, penalties LAST**, and a big conditional scorer (`> BIG_CONDITIONAL_VP` = 3) gets `emphasized` so a "+5 per X" doesn't read like an ordinary +1. The detail-grid renders the per-bar legend rows (colour dot + label + value — these ARE the colour legend) and the multi-column card list (`grid auto-fill minmax(195px,1fr)`, penalties in a red-accented group last). **Hover cross-link:** hovering a bar segment highlights its matching legend row / card group and dims the rest (via a shared `hoverKey`); reverse works too. NO native `title` on segments (project rule — the legend rows are the premium affordance). Card chips reuse `JournalCardChip` (hover preview + fullscreen); milestone/award rows keep the floating tooltip. Styles in `victory_points.less` (`.vp-accent(<key>,<colour>)` mixin per segment family). Tests: `tests/client/components/overview/victoryPointsModel.spec.ts` + `VictoryPointsOverlay.spec.ts`.

**Server breakdown extensions (the only server changes — additive, backward-compatible).** `VictoryPointsBreakdown` (`src/common/game/VictoryPointsBreakdown.ts`) gained:
1. `terraformRatingBreakdown: {base, temperature, oxygen, oceans, venus, cards}` — TR attributed BY REASON. The four parameter fields come from the player's existing **`globalParameterSteps`** (each step = 1 TR); `cards` is direct card/effect TR tracked in a NEW `player.terraformRatingFromCards` accumulator; **`base` is the reconciling remainder** (`terraformRating − temperature − oxygen − oceans − venus − cards`, ≈ the starting 20) so the six parts ALWAYS sum to the displayed rating exactly. `increaseTerraformRating(steps, opts)` adds to `terraformRatingFromCards` UNLESS `opts.global === true`; the 5 global-parameter call sites in `Game.ts` (oxygen/venus×2/temperature/oceans) pass `{global: true}` (already covered by `globalParameterSteps`). Serialized as `terraformRatingFromCards?` (default 0 → old saves degrade gracefully: card-TR folds into base).
2. `detailsCards[].kind: CardVictoryPointsKind` (`'resource'|'conditional'|'fixed'|'penalty'`) — classified server-side in `calculateVictoryPoints.classifyCardVictoryPoints` from `card.victoryPoints` (number → fixed; `{resourcesHere}` → resource; other countable → conditional; `'special'` → resource iff `card.resourceType` set, else conditional) with net-negative always `penalty`. System sources (Turmoil/Colony/Underworld) tagged explicitly.
Both flow through `VictoryPointsBreakdownBuilder` (`setTerraformRatingBreakdown` is display-only, NOT added to the total) and the empty init in `ServerModel.getPlayer`. `GameEnd.vue` is unaffected (additive). Tests: `tests/calculateVictoryPoints.spec.ts`.

**Client test runner gotcha:** `npm run test:client`'s mochapack needs `--webpack-config webpack.config.js` when invoked directly (`npx mochapack --webpack-config webpack.config.js --require tests/client/components/setup.ts "<spec>"`); a PURE helper with no Vue deps (like `victoryPointsModel.spec.ts`) also runs under the server runner (`npx mocha --import=tsx --require tests/testing/setup.ts "<spec>"`).
