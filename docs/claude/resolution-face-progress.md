# «Лицо резолюции» — журнал прогресса

Задание: `docs/claude/prompts/resolution-face-design.md` (выдано 2026-09-22). Дизайнерская задача: лицо
резолюции обязано читаться ДРУГОЙ СУЩНОСТЬЮ, а не картой проекта другого цвета.

Кадры лежат в `screenshots/resolution-face/` (каталог в `.gitignore`; пересъёмка — раздел «Как переснять»).

## Диагноз старого лица (по коду и кадрам, до правки)

- Лицо — общий каркас проекта один в один: золотая 9-patch рамка, гранёная плашка имени сверху, окно арта
  посередине, панель механики, плита внизу. Отличие — только тема `resolution` (фиолетовый лак) и эмблема
  партии 40 px на месте меток. Боковым зрением это «ещё одна карта», а фиолетовый рядом с розово-сливовой
  прелюдией читается как её оттенок.
- Над эффектом печатается мятный рельс «ПРИ РОЗЫГРЫШЕ» (`pcard-play-rail`): словарь карты проекта, которого у
  резолюции нет вовсе — её не разыгрывают.
- Плита задания: золотая рамка 290×62 px + поля 28 px = ~90 px из 460, то есть пятая часть лица отдана условию,
  которое НЕ является эффектом карты; кикер «ЗАДАНИЕ ПРЕДСЕДАТЕЛЯ» 8 px нечитаем ниже ×0.8 и повторён на
  каждой карте.
- На ×0.3 (96×138 px) от лица остаётся фиолетовый прямоугольник с пустой золотой рамкой внизу: партия (эмблема
  12 px) не читается, формула — 7-пиксельные иконки.
- В консоли `filter` и `text-shadow` сняты навсегда (`console_paint_baseline.less`), поэтому всё, на чём
  держалась «премиальность» каркаса (drop-shadow плашки, гравировка заголовка), в игре не рисуется.

## Блок A · три направления (эскизы в витрине)

СТАТУС: **СДАН**. Живые эскизы: `?resolutionsPlayground` → секция «Face directions». Один компонент
`ResolutionFaceSketch.vue` (`direction: charter | standard | slate`), стили
`console_resolution_face_sketches.less`. Во всех трёх — ОДНА отрисовка формул (`PremiumMechanicsPanel` /
`PremiumMechNode`), общий арт-пайплайн, дизайн-пространство 320×460 и консольно-безопасные материалы
(градиенты, `clip-path`, `box-shadow`, SVG-штрих; ни одного `filter`).

Общее для всех трёх (снимает обе частные претензии владельца):
- **задание — не блок**: строка-сноска «[кресло] [графика условия]», без рамки и без слов. Кресло — тот же
  знак, которым Парламент уже помечает председательство (`con-parl__seat-glyph`, чип «ПРЕДСЕДАТЕЛЬСТВО»), так
  что подпись на каждой карте не нужна: слова живут в блоке правительства и в колонке осмотра;
- освободившиеся ~55 px отданы формуле: иконки эффекта 31–34 px вместо 24–27;
- мятный рельс «при розыгрыше» снят; строка победителя голосования выделена структурно
  (`MechGroup.winnerRow` — факт печатной строки, выводится из DSL по знаку `VOTE_WINNER`).

| | Замысел одной фразой | Силуэт | Партия |
| --- | --- | --- | --- |
| **A · «Грамота»** | Законопроект — это ДОКУМЕНТ: лист с загнутым углом, перехваченный веленевой лентой с заголовком и скреплённый печатью партии-автора | лист с загнутым правым верхним углом, острые углы, без золотой рамки | печать 80 px на стыке арта и ленты + цветная кромка ленты |
| **B · «Штандарт»** | Резолюция — знамя партии, которая идёт к власти: вымпел в эмали её цвета | вымпел с остриём вниз | весь корпус в цвете партии, эмблема 90 px |
| **C · «Планшет»** | Резолюция — запись законодательного терминала: стеклянный слейт в языке самих панелей консоли | срезанные по диагонали углы, без рамки | цветная кромка слева + чип эмблемы |

Кадры: `screenshots/resolution-face/lab/<профиль>-peripheral.png` (рядом с «Искусственным озером», «Птицами»,
«Астероидом», прелюдией «Субсидия» и старым лицом), `…-extremes-<направление>.png` (×0.2 · ×0.3 · ×0.55 · ×0.8 ·
×1.12 против старого), `…-parties-<направление>.png` (весь каталог, все партии).

### Отбор: A · «Грамота»

Выбрана «Грамота», потому что только она проходит ОБА жёстких теста сразу и при этом несёт механику, а не
украшение. Боковое зрение: светлая лента поперёк тёмного листа, арт от самого верхнего края (у проекта там
тёмная плашка с жёлтым квадратом цены) и загнутый угол — универсальная пиктограмма «документ» — отличают её
от любой карты проекта тремя независимыми признаками, и ни один не завязан на цвет. Масштаб: на ×0.2–0.3
остаются ровно те три массы, которые нужны (арт · светлая лента · диск печати), а всё мелкое — сноска, водяные
линии, кромки — честно уходит в фактуру, не оставляя пустых рамок. Механика читается анатомией: автор —
печать, тело — статьи, особое положение победителя — выделенная статья, условие, которое закон учреждает, —
сноска под чертой.

Чем платим. Лента — светлый материал, которого у проектных карт нет (есть только у корпораций), и лицо
остаётся без общей золотой рамки: «одна вселенная» держится на типографике (Prototype), общей иконографии
формул, печатях партий и серебряно-фиолетовой палитре самого Парламента. Заголовку досталось 200 px вместо
250 — длинные имена уходят на 3 строки капсом 11.5 px.

Что теряем. «Штандарт» давал самый эффектный силуэт, но (1) корпус в цвете партии возвращает ровно ту
путаницу, с которой пришла задача: Зелёные читаются изумрудным проектом, Красные — событием, Индустриалисты —
корпорацией; (2) остриё съедает 68 px, и трёхстрочная формула («Климатические исследования») уже упирается в
задание; (3) говорит «партия», а объект — закон. «Планшет» ближе всех к языку консоли — и в этом его
поражение: в слоте, который сам тёмная стеклянная панель, он перестаёт быть ПРЕДМЕТОМ, а на ×0.3 от него
остаётся тёмная карта с картинкой сверху.

## Как переснять

```bash
npm run build:server && PORT=8123 node build/src/server/server.js   # свой сервер
npm run make:css && npm run build:client
node .claude-work/face/shoot.mjs fhd|tv|deck [outDir] [фильтр блока]   # скрипт локальный, вне репозитория
```
