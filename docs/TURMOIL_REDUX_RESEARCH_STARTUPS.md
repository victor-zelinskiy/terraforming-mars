# Turmoil Redux · TR46 Research Startups («Исследовательские стартапы»)

Карта проектов набора (2026-10-12). Синяя, 8 M€, метки Науки и Здания, держатель data, требование — плашка УЧЁНЫХ.
Розыгрыш «+3 data сюда»; ЭФФЕКТ «продаёте патенты → +1 data сюда за каждую проданную карту»; ДЕЙСТВИЕ «сбросьте ВСЕ data
отсюда → столько же карт из колоды → 1 в руку, остальные в сброс» (раз в поколение). Впервые в наборе: **СТОЛ ОТВЕЧАЕТ НА
ПРОДАЖУ ПАТЕНТОВ** (форк-хук с числом проданных карт и ставка ответа на модели промта) и **действие переменной величины X**.
Карта — ≈ 30 %; остальное — два момента, которых в консоли не было: (1) игрок видит ответ стола на продажу ДО подтверждения,
растущим вместе с выбором, и видит, как терминал платит data в капсулу карты; (2) «X data → X карт → взять 1» — X назван до
нажатия, все X карт приходят из колоды, одна — в руку, остальные — в сброс.

Промт: `docs/claude/prompts/project-tr46-research-startups.md`. Соседи: TR18 Martian Fiber (ответ на ответ — «+1 M€ за
каждую data»), TR28 (bespoke-действие класса «трата → товар»), TR45 (`docs/TURMOIL_REDUX_COMPOSTING_INITIATIVE.md` — класс
«счётный розыгрыш», чьи читатели PL-196 расширил), RX24 Open IP Trade (сцена продажи, переиспользованная без своего действия).

## 1. Сервер — ответ стола на продажу

- **Хук.** `ICard.onPatentsSold?(player, sold: ReadonlyArray<ICard>)` — зовёт ОДИН писатель: `SellPatentsStandardProject`
  после сброса и строки журнала (`patentsSold` — обход `player.tableau`, каждый ответ под `events.withEffect(player, reactor,
  'standard-project', …)`). Прогноз-близнец в файле карты: `patentsSoldForecast?(owner, count)` → `EffectForecastFact[]`
  (пара в `FORECAST_HOOK_PAIRS` — гард покрытия не даёт хуку без близнеца).
- **Корень события (P0, PL-202).** У продажи не было корня в записи событий: «+N M€» терялись, ответ TR46 висел сиротой.
  Колбэк продажи обёрнут `commitInScope`; продажа — конверсия, не стандартный проект в счёт финала (`endgameFacts`
  `CONVERSION_STANDARD_ACTIONS`).
- **Ставка на промте (К-S1, PL-204).** `SelectCard.markPatentSale(reader)` → `SelectCardModel.patentSale: PatentSaleModel`
  (`{megacreditsPerCard, answers?}`) — сервер отдаёт ПРАВИЛО ЗА ОДНУ КАРТУ: `patentSaleModel(player, project)` =
  `effectForecast.patentSaleFacts(player, project, 1)` (ответы стола в порядке живого обхода + каскад — Fiber после data —
  + ответ на M€) с чипами без `current/resulting` и нотой «За каждую проданную карту». Клиент только умножает. Ставка 1 M€ —
  `SELL_PATENTS_MEGACREDITS_PER_CARD` (`standardProjects/patentSale.ts`), клиентская константа удалена. Гард паритета
  `tests/models/patentSaleModel.spec.ts`: ставка × N = исполнение на 1 / 3 / 5 картах, с Fiber и без.
- **Журнал.** «продал N патентов» + строка эффекта «+N data на Исследовательские стартапы — за N проданных патентов»
  (базис `{count, unitKey: '{patent|patents} sold'}`); счётный выигрыш с базисом внутри эффекта не сворачивается в маркер
  эффекта (PL-203).

## 2. Клиент — сводка продажи и сцена терминала

- **Сводка** (`.con-hand__salebar`): после M€ — ответы стола (иконка · +N · имя карты), живые на каждый выбор, из ставки
  сервера (`patentSale/patentSaleAnswers.ts`: `patentSaleAnswers` · `patentSaleSummary`); при 0 выбранных — построчно «за
  карту», никогда «+0». Ряд «Продажа патентов» в СТАНДАРТНЫХ ПРОЕКТАХ — дверь прогноза (R3) с той же ставкой.
- **Сцена** (`consolePatentSale.ts`, решение 6): на фазе `inserting` у терминала поднимаются КАРТЫ-ПОЛУЧАТЕЛИ
  (`.con-sale-hero`, миниатюры с тёплым артом — thumb + decode), выплата ждёт, пока они встанут (`receiversStanding`); ОДНА
  волна из щели — M€ проекта на рельс и data в капсулу TR46 (`[data-played-key]` — ступень лестницы адресов
  `consoleResourceTransfer`); ответы на запас (Fiber «+N M€») летят ПОСЛЕ — с лица своей карты-получателя, затем
  получатели уходят. Холды ответов сеются в блоке применения транспорта (`seedPatentSaleRewardHold` из
  `gameTransport.seedRewardHolds`) — рельс не показывает «фантом» до касания; на конце / отмене холды отпускаются. Сцена
  длиннее на ≈ 0,5–0,7 с (подъём получателей) — принято владельцем.

## 3. Действие «X → X карт → 1»

- `ResearchStartups.activationAt(player, dataHere)` — ОДНО чтение X: `{spent, revealed: min(data, deck), kept, discarded}`
  для превью, причины и исполнения. 0 data → причина «${0} из 1 data на этой карте»; пустая колода → `deckEmpty`.
- Исполнение: `removeResourceFrom` (без лога) + строка журнала «сбросил X data … чтобы посмотреть X карт» → X ≤ 1 —
  `drawCard` (без выбора, карта показана), иначе `drawCardKeepSome(keepMax 1)` с `promptSource` карты. Выбор — скрытая
  информация, НЕ пре-собирается: шаг после нажатия в том же workspace (`ДЕЙСТВИЯ КАРТ › ИССЛЕДОВАТЕЛЬСКИЕ СТАРТАПЫ ›
  ДОБОР КАРТ`).
- Превью: `[cardCost(this, spent), deckLookGain(revealed, kept)]` — чип добора несёт `look: {revealed, keep}` и читается
  «из 5 вскрытых · 4 в сброс» (`ActionEffectChip`, `data-chip-look`).
- **Роль держателя (К-R1).** У bespoke-действия нет декларации — роль объявлена ПОЛЕМ карты рядом с действием
  (`holderActionGood = {spend: 'all', good: {kind: 'look', keep: 1}}`, читает `holderActionGoodOf`): спутник ДОП. РЕСУРСЫ
  и чип держателя говорят «Всё отсюда: столько же карт с колоды, 1 в руку», а не «просто хранение».
- **Отлёт траты (PL-201).** У добора не было рельсовой половины коммита: капсула 5 → 0 тикала без жетона. Теперь трата
  добора — звено цепи (`SpendContext.resultElsewhere` — результат принадлежит сцене колоды), жетон рождается на капсуле
  героя и впитывается печатным рядом; заявленный путь (claimed) больше не роняет план коммита.

## 4. Лицо, локаль, лор, арт

Лицо: эффект `[плашка «Продажа патентов»] : +1 [data]*`, действие `X [data] → X [карты]* (оставить 1)`, розыгрыш
`+3 [data]` цифрой; порядок — действие → эффект → розыгрыш. `infoText`: эффект и действие короткими блоками. RU-ключи
`turmoil_redux_cards.json` · `card_info.json` · `log_messages.json` · `ui.json` · `effect_forecast.json` · `console.json`.
Лор TR46 EN/RU. Арт `assets/card-images/TR46.webp` + thumb.
