# Turmoil Redux — «Парламент» v6: три инструмента под одной фиксированной строкой

Дата: 2026-09-16. Продолжение `TURMOIL_REDUX_PARLIAMENT_V5.md` (постоянная зона делегатов, бюджеты высоты, счёт
внутри колонки) и `TURMOIL_REDUX_RESOLUTION_INSPECT.md` (fullscreen-осмотр). Правила игры, каталог резолюций,
серверная модель голосования и MarsBot не менялись. Итерация — визуальная иерархия основного workspace: общий осмотр,
режим голосования, представление партий, единая верхняя строка и графический язык заданий. Документ фиксирует
**оценку исходного экрана**, **концепцию**, **что изменилось**, **контракты**, **бюджеты по профилям**, **проверку** и
**честные ограничения**.

## 1. Концепция — «три инструмента, один язык»

1. **Фиксированная верхняя строка.** `⚖ ПАРЛАМЕНТ › ОСМОТР` / `› ГОЛОСОВАНИЕ` в зарезервированной ширине заголовка
   (`--con-parl-crumb-w`); зона делегатов живёт в trailing-зоне `ConsoleWsHead` **постоянно**, выровнена от левого
   края, и в режиме голосования **не телепортируется** — координаты одинаковы по построению.
2. **Правительство.** Крупная принятая карта; правящая партия с крупной формулой и одной подписью «У всех игроков»;
   собственный эффект принятой резолюции — отдельная строка под своей меткой (только когда он есть); задание —
   графика, прогресс, награда, председатель.
3. **Голосование.** Один акцент лидера (золотой бейдж + шов слота), шапка без дубля; карты крупнее. Состояния
   различаются характером: cyan = фокус управления, gold = лидерство, mint = личный доступ, цвет партии = материал.
4. **Партии.** Формула в центре плитки в полный масштаб; в подвале — гнёзда `n/2`, одно слово только там, где оно
   говорит больше гнёзд («Правит», «Ваш эффект»), поддержка справа; приглушение не гасит механику (0.82).
5. **Режим голосования.** Без строки зоны — высота уходит картам. Информационная область: **главный блок «Эффект
   резолюции»** (широкая колонка, крупная графика + фразы по времени действия: «При принятии», «Победителю
   голосования», «Эффект», «Действие»), сбоку компактно партия (эмблема · имя · формула · «При принятии — всем
   игрокам») и условие задания; справа — источник, полный прогноз с выделением изменений и кнопка **с ценой**
   («из лобби · бесплатно» / «из резерва · 5 М€»).
6. **Задания через графику.** Тип карты — нативный глиф: обложка карты с шапкой цвета типа (`cards(n,
   {secondaryTag: BLUE|GREEN})`), никаких текстовых плашек.

## 3. Контракты

- **Крошка** — `crumbSubject`: browse/seat/submitting-seat → `Parliament overview`; vote/paying/landed → `Voting`;
  recap → `Results`; стадии: paying → `Payment`, seat → `Seat`. `selectVoteSlot` больше не пишет subject в стек
  (крошка режима стабильна). Зарезервированная ширина рассчитана на самую длинную крошку `ГОЛОСОВАНИЕ › ОПЛАТА`.
- **Зона** — trailing-слот `ConsoleWsHead`; `.con-parl__head .con-wshead__aux { flex: 0 0 var(--con-parl-crumb-w) }`,
  `.con-wshead__trailing { margin-left: 0; flex: 1 1 auto; justify-content: flex-start }`, `.con-parl__head { flex-wrap: wrap }`.
  Источники полёта неизменны: `[data-parl-seat-lobby=c] .player-cube`, верхний куб `[data-parl-seat-reserve=c]`,
  `[data-parl-neutral-cube]` — теперь всегда в шапке, в обоих режимах.
- **Собственный эффект** — `VoteInfo.ownParts: {key, label, text}[]` (effect → `When enacted`, winner → `For the
  winner of the vote`, passive → `Resolution effect`, action → `Resolution action`) — те же ключи, что у
  `resolutionAnnotations`; `enactedOwnMechanics` — графика принятой резолюции в правительстве.
- **Цена** — `ctaCost: {kind: 'free' | 'cost' | 'none', amount}` из `benchSource` + `votePayment.cost ?? voteTile.cost`;
  `[data-parl-cta-cost][data-cost-kind]` — e2e-свидетель.
- **Плитка** — `ConsolePartyPlaque` `tile`: `stateText` только `ruling-default` («Правит · стартовое правило»),
  `ruling`, `delegates` («Ваш эффект»), `granted`; гнёзда + `__places-count` для in-area/progress/delegates.
- **Глиф типа карты** — `mechItemIcon(CARDS + secondaryTag BLUE/GREEN)`; никакого баббла (`bubbleUrl` их не знает).
- **Метка в формуле** — `mechItemIcon(TAG)` теперь несёт `mod: 'tag'`; лицо карты этот класс не стилизует (голая
  графика как прежде), Парламент — медальон.

## 6. Ограничения (честно)

- Награда Повестки за карту (`agenda-step` в `ConsoleBoardCardBonusLayer`) в этой итерации не перепроверялась в
  игре — код не менялся; повторное открытие не переигрывает награду по конструкции (`lastAdvanceSeq` только на
  живое изменение, reveal потребляется один раз).
- На TV и 1080 при пяти игроках шапка становится двухъярусной (зона под крошкой) — одинаково в обоих режимах, но поле
  ниже на одну строку; на Deck при пяти местах имена игроков скрыты (куб — идентичность).
- Реальные резолюции проверены на dev-примерах (`copies: 0`); арты резолюций — печати партий в окне арта.
- Record headless: Playwright под нагрузкой роняет кадры; движение сверялось по DOM-таймлайну и кадрам вместе.
