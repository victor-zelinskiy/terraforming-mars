# TR10 · Fringe Colony («Окраинная колония») — первая карта СОСТАВА колоний

**Статус: СДАНА 2026-10-03** (v1 — границы в §5 и в `docs/COLONY_ROSTER_CEREMONY.md` §8). Печатный текст: «This can
only be played during generation 4 or later. Remove from play a colony tile that has NO COLONIES, TILES, OR TRADE FLEETS
ON IT. Replace it with a new colony tile of your choice, and place a colony on it, if possible.» Стоимость 24, зелёная
(AUTOMATED), метки Юпитер + Космос, требование «ПОК. 4+», 1 ПО, ▲ Колонии (`compatibility: 'colonies'`). Лор: «To boldly
go where no businessman has gone.» → «Смело идти туда, куда не ступала нога бизнесмена.»

Карта мала; её вес — фреймворк «состав колоний» (`docs/COLONY_ROSTER_CEREMONY.md`), который она ввела и который
получают Aridor, соло-сетап и MarsBot-Aridor.

Файл карты: `src/server/cards/turmoilRedux/FringeColony.ts` (шапка — чтение скана и правила 1–10). Спеки:
`tests/cards/turmoilRedux/FringeColony.spec.ts`, `tests/deferredActions/ReplaceColonyTile.spec.ts`,
`tests/colonies/ColonyRoster.spec.ts`, e2e `tests/e2e/console-fringe-colony.spec.ts` (фикстура `fringe-colony`).

## 1. Чтение скана

Цена 24 · плашка MIN с ТЕКСТОМ «GEN 4+» — требование `{generation: 4}` (новый вид `GENERATION`, тропа TR02: причина
«Требуется поколение 4 или позже · Сейчас: N», компакт руки «Пок. 2/4», плашка лица текстом «ПОК. 4+») · метки Юпитер,
Космос · ряд «− [плитка]* + [плитка] [▲]*» · серый ярлычок у второго астериска — НОМЕР карты «TR10» (читается «TRIO»),
не правило · 1 ПО на диске Марса.

## 2. Правила чтения (каждое закреплено спеком)

| # | Правило |
| --- | --- |
| 1 | `game.generation >= 4`; до 4-го поколения карта неиграбельна, причина называет «сейчас» |
| 2 | Уйти может плитка В ИГРЕ без колоний (ничьих, куб MarsBot — колония) и без флота; активность и трек не важны; «TILES» сегодня пустое множество — один предикат `colonyTileOccupiedReason` |
| 3 | Кто не может — отключён с ОДНОЙ причиной (колонии → флот), никогда не скрыт; единственный кандидат всё равно выбирается |
| 4 | Приходит любая плитка РЕЗЕРВА; входит по правилу движка (активна по классу или по карте её ресурса в чьём-то табло), трек — стартовый |
| 5 | Новая плитка встаёт НА МЕСТО снятой (тот же индекс, без пересортировки); снятая — в резерв как в коробке |
| 6 | Колония игрока на новую плитку, слот 1, с наградой и триггерами (`Colony.addColony`); невозможно (войдёт неактивной; не по карману РТ награды) → замена происходит, колония — названный пропуск |
| 7 | Нет пустой плитки (или пуст резерв) → карта играбельна, эффект целиком — названный пропуск, двери нет |
| 8 | Не торговля и не дополнительная плитка: число плиток, флоты, прочие треки не тронуты |
| 9 | Журнал: одна строка замены + событие `colony-roster-changed` под картой, затем строки постройки |
| 10 | MarsBot карту не играет; за столом с ботом человек играет её как обычно (порядок `game.colonies` сохранён) |

## 3. Решения владельца (приняты по умолчанию — подтвердить)

1. RU-имя «Окраинная колония». 2. Снятая плитка возвращается в РЕЗЕРВ (в кандидаты этого розыгрыша не входит).
3. Замена наследует слот; добавление (Aridor) сохраняет сортировку движка. 4. Нет кандидата → карта играбельна, эффект —
названный пропуск. 5. Кандидат без колонии остаётся выбираемым (причина на нём до нажатия). 6. «TILES» = пустое
множество. 7. Хореография — ритуал TR03/TR07 в три уровня, конец — посадка плитки в слот. 8. Зрителю — журнал всегда,
церемония на сетке только при открытой сетке, авто-открытия нет. 9. Плитка, входящая за стол MarsBot, садится по
правилу стола (активна, трек на 2-й клетке) — одной веткой во входе; Rule Book о позже входящих плитках молчит.
10. Плашка требования — текстом «ПОК. 4+». 11. Maria и Prospecting получают серверный путь, визуально не принимались.
